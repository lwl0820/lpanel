# 后端开发规范

开发前阅读当前任务的需求与设计，再按改动范围查看运行契约和代码示例。会话、文档和注释使用中文。接口与部署行为变更时，同步记录验证过的实际契约。

| 文档 | 适用范围 |

| [基础运行契约](./runtime-contract.md) | CLI、API 会话、配置和操作状态 |
| [网站、项目、证书与升级](./hosting-contract.md) | 业务托管、部署、卸载和发布 |
| [宿主机文件管理](./server-files.md) | 管理员文件接口、代理上传和文本读写 |

| [数据库](./database-guidelines.md) | SQLite 查询、表初始化和回滚 |
| [错误处理](./error-handling.md) | 接口错误、长操作与生效检查 |
| [质量要求](./quality-guidelines.md) | 按范围选择检查和真实环境验收 |
| [日志](./logging-guidelines.md) | systemd 日志、操作输出和脱敏 |

验证范围跟随改动。跨层接口改动同时核对前端调用。实际系统能力在隔离环境验收，记录命令替身与真实运行的覆盖范围。缓存和临时文件放在仓库 `.tmp`。

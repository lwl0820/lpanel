# 宿主机文件管理

**范围**：`/api/v1/server/files` 管理宿主机而非面板安装目录，所有操作共用管理员会话。前端「服务器管理」默认打开 `/server/files`。没有通用命令执行接口。

| 在接口前缀后的路径 | 请求 / 响应 |
| --- | --- |
| `GET /list?path=…` | 目录的绝对路径；返回 `path`、`entries` 和 `skipped_names`。每项含 `name`、`path`、`kind`、字节数 `size`、`modified_at`。类型为 `dir`、`file`、`link` 或 `other`。非 UTF-8 文件名不转成可操作路径，以跳过数量提示，避免误操作同名的 `�` 文件。 |
| `PUT /upload?path=…`、`GET /download?path=…` | 上传请求体是原始文件字节，不是 JSON；目标必须是新文件。下载响应是附件流。 |
| `GET /text?path=…`、`PUT /text?path=…` | 读写 `{ "text": "…" }`。仅编辑已有、最多 1 MiB 的 UTF-8 纯文本；不能因 JSON 转义放大而按传输长度误判文件太大。 |
| `POST /mkdir`、`POST /rename` | JSON 分别为 `{ "path": "…" }` 和 `{ "path": "…", "name": "新名称" }`。重命名留在同一目录，不覆盖已有项。 |
| `DELETE ?path=…`（前缀本身） | 仅删除所选普通文件、符号链接本身或空目录，不递归删除；写操作成功统一返回 `{ "ok": true }`。 |

**边界与验收**：未登录的普通入口返回 401，自定义入口继续隐藏匿名 API。用工作区 `.tmp` 下的独立目录测试，不在实际系统文件上演练编辑或删除。同名上传失败须保留原内容，删除非空目录失败须保留子项，下载链接不能读取链接目标。路径用 `URLSearchParams` 编码，不直接拼接文件名，否则 `#` 会被当作 URL 片段。

新建目录和重命名的 POST 只接受 JSON 媒体类型。删除非空目录返回 `409 directory_not_empty`；原地保存文本发生部分写入或关闭失败时返回 `text_save_incomplete`，调用方不能宣称原文件完好。附件在输出中途读取失败时中断传输，不在文件字节后拼接错误响应。

**代理**：面板生成的 Nginx 配置仅对精确的上传路径取消请求体大小限制并关闭请求缓冲；文本路径允许容纳 JSON 转义，Go 端仍按文件字节校验。业务站点和其他面板接口不继承这些设置。用超过 1 MiB 的文件通过面板实际访问端口验证传输，直连后端不能证明代理配置生效。

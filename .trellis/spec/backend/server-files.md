# 宿主机文件管理

**范围**：`/api/v1/server/files` 管理宿主机而非面板安装目录，所有操作共用管理员会话。前端「服务器管理」默认打开 `/server/files`。没有通用命令执行接口。

| 在接口前缀后的路径 | 请求 / 响应 |
| --- | --- |
| `GET /list?path=…` | 目录的绝对路径；返回 `path`、`entries` 和 `skipped_names`。每项含 `name`、`path`、`kind`、字节数 `size`、`modified_at`、八进制权限字符串 `mode` 和属主 `owner`（用户名，无法解析时为数字 UID 字符串）。类型为 `dir`、`file`、`link` 或 `other`。非 UTF-8 文件名不转成可操作路径，以跳过数量提示，避免误操作同名的 `�` 文件。 |
| `PUT /upload?path=…`、`GET /download?path=…` | 上传请求体是原始文件字节，不是 JSON；目标必须是新文件。下载响应是附件流。 |
| `GET /text?path=…`、`PUT /text?path=…` | 读写 `{ "text": "…" }`。仅编辑已有、最多 1 MiB 的 UTF-8 纯文本；不能因 JSON 转义放大而按传输长度误判文件太大。 |
| `POST /mkdir`、`POST /rename` | JSON 分别为 `{ "path": "…" }` 和 `{ "path": "…", "name": "新名称" }`。重命名留在同一目录，不覆盖已有项。 |
| `DELETE ?path=…`（前缀本身） | 删除普通文件、符号链接本身，或递归删除选中的目录及其内容。写操作成功返回 `{ "ok": true }`。 |

**边界与验收**：未登录的普通入口返回 401，自定义入口继续隐藏匿名 API。用工作区 `.tmp` 下的独立目录测试，不在实际系统文件上演练编辑或删除。同名上传失败须保留原内容，递归删除目录时须保留外部符号链接的目标，下载链接不能读取链接目标。路径用 `URLSearchParams` 编码，不直接拼接文件名，否则 `#` 会被当作 URL 片段。

删除所选目录前检查挂载边界。选中挂载点或目录含嵌套挂载时返回 `409 directory_contains_mount`。预检通过后，若递归删除未能完成，返回 `500 directory_delete_incomplete`，提醒用户刷新核对剩余内容。新建目录和重命名的 POST 只接受 JSON 媒体类型。原地保存文本发生部分写入或关闭失败时返回 `text_save_incomplete`，调用方不能宣称原文件完好。附件在输出中途读取失败时中断传输，不在文件字节后拼接错误响应。

**代理**：面板生成的 Nginx 配置仅对精确的上传路径取消请求体大小限制并关闭请求缓冲；文本路径允许容纳 JSON 转义，Go 端仍按文件字节校验。业务站点和其他面板接口不继承这些设置。用超过 1 MiB 的文件通过面板实际访问端口验证传输，直连后端不能证明代理配置生效。

## 批量操作与属性

前端逐项调用管理员文件接口，向用户显示成功数和失败条目的路径、原因。剪切成功后从待粘贴列表移除该项。

| 接口 | 输入与行为 |
| --- | --- |
| `POST /copy`、`POST /move` | JSON `{path, directory}` 指定源条目和目标目录，使用原名称。保留目录结构和链接本身。同名冲突返回 409，将目录粘贴到自身或下级返回 400。跨盘移动使用 GNU cp 保留权限、所有者、时间戳、扩展属性和目录树内硬链接，在目标完整发布后清理来源。目标发布后清理来源失败时返回 `move_source_cleanup_failed`。 |
| `POST /attributes` | JSON 中传 `path`，传入 `mode`、`owner` 中的一项或两项。普通权限例如 `"640"`，含特殊位例如 `"4750"`。属主可用宿主机用户名或数字 UID。默认只应用到所选条目。对目录传 `recursive: true` 时，同一次请求中的权限和所有者设置也应用到子文件和子目录。递归时跳过链接的权限，只对链接本身改属主。遇到嵌套挂载时跳过该挂载。单独设置链接权限返回 400。递归过程中已有条目生效后遇错，返回 `attributes_update_incomplete`。 |

## ZIP 压缩和解压

| 接口 | 请求与结果 |
| --- | --- |
| `POST /compress` | JSON `{directory,names,name}` 分别指定当前绝对目录、选中的直接子项名称列表和最终 ZIP 文件名。普通文件及目录以各自的名称放在 ZIP 顶层，保留层级和空目录。生成成功才在当前目录发布，已有同名文件时返回 409。 |
| `POST /extract` | JSON `{path,directory}` 指定 ZIP 文件和目标绝对目录。目标可以已存在，也可以是待建目录。顶层条目重名时提示选择其他目录。成功写操作均返回 `{ok:true}`。 |

压缩弹窗每次打开都生成新的随机 ZIP 名称，允许修改；解压弹窗预填当前目录。普通 ZIP 直接解开，文件管理中的解压操作不触发编排项目导入。链接、特殊文件和越界的归档路径会报错。带 Unix 普通权限的条目还原其读、写、执行位，所有者与特殊权限位不从 ZIP 恢复。解压到已有目录时先检查所有顶层名称，保留已有文件和目录。如果发布进行到一半遇错，接口返回 `extract_incomplete` 并提示核对目标目录。

## 分片上传

点选、拖入和粘贴共用当前目录和上传队列。浏览器在原生粘贴事件中收到具名文件时优先上传这些文件。文本输入框和编辑器保留原生粘贴。面板内的复制或剪切跨目录有效，使用按钮或文件列表快捷键粘贴。

| 接口 | 成功响应和约束 |
| --- | --- |
| `POST /uploads` | JSON `{path,size}` 以字节声明文件大小。返回 201 和 `{id,chunk_size}`，当前上限为 524288 字节。上传绑定到创建时的管理员会话。 |
| `PUT /uploads/{id}?offset=N` | 请求体为原始字节。偏移为已确认字节数，成功返回 `{received}`。偏移不匹配返回 409，超限返回 413。 |
| `POST /uploads/{id}/complete` | 收齐声明大小后发布并返回 `{ok:true}`。空文件可在创建后直接完成。缺片或已有同名目标时返回 409。 |
| `DELETE /uploads/{id}` | 放弃上传并清理暂存，成功返回 `{ok:true}`。会话失效或标识不存在时不能追加分片。 |

只有完成请求成功后才显示“已上传”；最后一个分片的确认仅表示字节已收齐。单片请求大小独立于整文件，原有整文件上传入口继续兼容。暂存位于目标文件系统，主动放弃和空闲 30 分钟会清理。进程意外终止后可能留下私有的 `.lpanel-upload-*` 目录。

接口测试覆盖偏移、零字节、同名发布冲突、分片中断和权限。代理验收设单次请求体上限 1 MiB，比对超限请求与多片上传的结果，再对下载内容计算摘要。[验收记录](../../../docs/validation.md)

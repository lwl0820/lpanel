# 宿主机交换空间

管理员从 `GET /api/v1/server/swap` 读取 `total_bytes`、`used_bytes`、`entries`。每项含有路径、类型、容量、已用量、启用状态和面板创建标记。总量取内核已启用项的可用字节数，交换头占用的页面会影响这个数值。停用的文件仍可显示文件大小。无法确定容量时返回 `null`。

| 管理操作 | 接口和参数 |
| --- | --- |
| 创建独立文件 | `POST /api/v1/server/swap/files`，例如 `{"size_mib":4096}` |
| 调整面板文件 | `POST /api/v1/server/swap/resize`，传入选中项的 `path` 和新容量 `size_mib` |
| 启停面板文件 | `POST /api/v1/server/swap/enable` 或 `/disable`，传入 `path` |
| 删除已登记的普通交换文件 | `DELETE /api/v1/server/swap/files?path=…`，路径按查询参数编码 |

写请求通过基本校验后以 HTTP 202 返回操作记录。页面通过 `GET /api/v1/operations/{id}` 查询最终结果。后台操作执行时重新核对类型和归属。系统交换文件和面板文件均可逐项删除。块设备、无法确认的条目均为只读。

列表合并内核交换项、开机配置和面板创建记录。同一分区可能以设备路径和 UUID 两种形式出现，应合并为一项。对于仍在使用的文件，先执行 `swapoff` 并确认停用，再移除对应的开机配置和文件。停用失败时保留文件及配置。调整容量需保留该文件之前的启用状态。

回归测试应覆盖停用失败、分区别名、外部交换文件的独立删除和带空格的路径。重启后实际启用结果须在有独立内核与磁盘的虚拟机中核对。

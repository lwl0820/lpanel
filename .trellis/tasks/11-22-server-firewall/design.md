# 防火墙设计

读接口返回宿主机防火墙状态及入站端口规则。写操作区分启用、停用、添加和删除规则。用已识别的本机防火墙管理程序执行；先在目标镜像验证停用时能检查待生效规则，再接入启用动作。不能确认规则优先级或存在未识别的冲突时，不启用。不清空宿主机规则集，不接管 Docker 转发规则。

启用操作从当前有效配置读取 `PanelPort`，检查对应协议、地址族及来源的实际匹配结果，缺规则时先补规则，再启用。面板在 Nginx 后面；遇到限定来源的规则，不能用 Go 接收到的回环地址代替客户端地址。若需要来源信息，应由面板自己的代理覆盖传入，不信任浏览器自报地址；无法判断时不扩大已有放行范围。不读取 SSH 配置，也不发 SSH 提醒。

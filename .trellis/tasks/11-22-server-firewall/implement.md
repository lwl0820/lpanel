# 防火墙实施清单

- [ ] 依赖文件子任务提供的导航入口。先在隔离机确认目标防火墙的规则顺序与启用前读写方式，记录可支持的配置，再接入状态、启停和单端口规则页面。
- [ ] 为非默认面板端口、已有放行和冲突规则补充定向用例；运行 `go test ./internal/panel -run '^TestServerFirewall'` 和 `npm --prefix web run typecheck`。
- [ ] 用独立客户端的新连接验证面板可访问；预置未放行的 SSH，通过面板手动添加规则后验证可重新连接。确认其他规则未变，无法确认面板放行时仍未启用。
- [ ] 核对停用后的系统状态，并在隔离机恢复测试前规则；不对开发宿主机执行启停。

# 服务器 DNS 设置

## 首版范围

管理员能查看和修改整台服务器默认使用的一组 DNS 地址，也能恢复修改前的默认配置。无论服务器有几块网卡，页面都只提供一组默认地址，没有网卡选择器。不修改各网卡的专用 DNS、按域名分流规则、容器专用 DNS 或公网域名记录。

## 验收标准

- [ ] 在受支持的隔离服务器上，页面显示实际使用的 DNS 服务器；地址格式有误时不提交修改，原设置不变。
- [ ] 将 DNS 改为可解析测试域名的服务器，刷新后能看到新地址；通过宿主机默认解析方式查询该域名能得到预设结果，重启后设置仍生效。
- [ ] 恢复原配置后，服务器重新使用原先的解析设置。不能管理的网络配置不显示为修改成功。
- [ ] 多网卡服务器也只显示一组默认地址；更新和恢复默认配置均不改写网卡上已有的专用配置。

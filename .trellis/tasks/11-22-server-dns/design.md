# 默认 DNS 设计

页面只呈现服务器默认使用的一组地址。读接口区分有效的上游地址与本机解析代理的回环地址；保存请求仅包含地址列表，不接收网卡名。恢复操作撤销面板对默认 DNS 的修改，不把各网卡的 DNS 合并后写回，也不覆盖按域名分流规则。

先识别系统默认解析配置的维护者。对由解析服务生成的文件，使用该服务的持久配置，不替换符号链接；对明确由管理员维护的静态配置，仅更改默认服务器地址，保留其他选项。保留首次修改前恢复默认配置所需的信息，连续保存不能覆盖恢复依据。不能可靠识别配置归属或已有链路规则导致无法验证默认设置时，说明限制，不报告修改成功。

写入后重新读取生效的配置；隔离机验收使用只有测试解析源知道答案的域名，通过宿主机默认查询路径验证，不通过直接指定 DNS 地址的查询代替。若保存未生效，报告实际状态并保留恢复入口。

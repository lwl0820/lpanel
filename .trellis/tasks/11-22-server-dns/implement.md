# 默认 DNS 实施清单

- [ ] 依赖文件子任务提供的导航入口。在 Debian、Ubuntu 目标镜像核对实际解析服务及配置归属，确定可持久修改的默认配置位置；不改每块网卡，也不为本功能更换系统解析服务。
- [ ] 接通读取、保存及恢复操作与一组地址的表单；用静态配置及服务生成配置的样本覆盖回读与恢复，运行 `go test ./internal/panel -run '^TestServerDNS'` 和 `npm --prefix web run typecheck`。
- [ ] 在隔离机通过系统默认解析路径查询测试域名，重启后复验。连续修改后恢复最初设置，检查默认查询和已有网卡专用配置。分别记录实际验证的配置类型；不调整开发机 DNS。

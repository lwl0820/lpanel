# 使用 Go 构建服务器管理面板

## 目标与背景
让服务器管理员通过中文 Web 面板部署 Docker Compose 项目、托管静态网站，并通过域名和自动证书开放访问；提供一键安装和版本升级能力。

仓库目前只有 Trellis 初始化文件，没有业务代码。用户已确认下列首版范围和全部集中建议；需求澄清与完整规划审阅完成，已批准实施。原有 00-bootstrap-guidelines 任务保持原状。

## 功能需求
| 编号 | 首版需求 |
| --- | --- |
| R1 | 后端使用 Go，前端访问入口使用 Nginx；域名旁提供“自动申请证书”，勾选后通过 Let’s Encrypt 签发并开启 HTTPS，支持自动续期。 |
| R2 | 参考 1Panel 的操作方式，接收用户 Compose 配置及环境变量；扫描 ports、expose 并区分宿主机发布端口和容器内部端口；用户选择已发布的 HTTP/HTTPS 服务端口绑定域名，支持 WebSocket 和自动证书。仅 expose 时提示补充 ports；非网站端口仍由 Compose 部署，不提供通用 TCP/UDP 代理。 |
| R3 | 添加静态网站时指定服务器已有目录，支持单页应用路由回退；可以绑定域名并勾选自动证书。 |
| R4 | 自动获取最新正式版本，每日检查且支持手动检查；显示升级提醒，由用户点击触发下载和升级，保留配置与业务数据，失败恢复上一版程序；发布源使用可配置的 GitHub Releases。 |
| R5 | 前端使用 Vue 3 和 Element Plus。 |
| R6 | 提供一键安装脚本；配置管理员、密码、面板端口，并可选择绑定域名和申请证书；签发成功后安装结束即可通过 HTTPS 访问，输出实际地址。 |
| R7 | Compose 项目支持配置编辑、部署、启动、停止、重启、状态、日志和删除；删除时保留数据卷及挂载目录。 |
| R8 | 面板端口始终保留安装时的配置，默认 8443；HTTPS 地址为 https://面板域名:面板端口，业务网站使用标准 80/443。 |
| R9 | 证书使用 HTTP-01，用户需将普通域名解析到服务器并开放公网 80；申请失败时保留 HTTP、显示原因并支持重试，不能显示为 HTTPS 已启用。 |
| R10 | 优先支持干净服务器，复用已有可用 Docker；已有非本面板管理的 Nginx 或端口冲突时提示并停止相关安装步骤，不覆盖旧配置，不自动迁移其他面板。 |

## 兼容性与项目约束
- 首版支持 Debian/Ubuntu，覆盖 amd64、arm64；具体版本验证矩阵见技术设计。
- 面板使用 Go 二进制并由 systemd 管理，Nginx 和 Docker 运行在宿主机上。
- 会话、文档、注释和产品界面使用中文；不将开发需求和内部实施说明展示在产品界面。
- 临时文件仅放在工作目录的 .tmp 内；优先简单直接的实现，不提前抽取单次使用的辅助函数，不为假设性问题擅自增加防御设计。
- 后续问题与建议集中列出，不再逐项询问。

## 首版不包含
完整复刻 1Panel、应用商店、可视化编排、多机或集群管理、通用 TCP/UDP 代理、数据库管理、在线文件管理、静态文件上传、Git 自动构建、泛域名证书、DNS 服务商 API、其他面板自动迁移、无人值守自动安装更新。

## 验收条件
| 编号 | 可观察结果 | 对应需求 |
| --- | --- | --- |
| A1 | 前后端可构建，经 Nginx 进入中文面板；安装配置的管理员可登录，错误密码和未登录请求无法执行管理操作。 | R1、R5、R6 |
| A2 | 有效 Compose 配置及环境变量可部署；短、长格式端口均列出服务与目标端口；多个端口能明确选择，ports 与 expose 不混淆。 | R2 |
| A3 | Compose 应用绑定域名后可访问对应服务，WebSocket 可用；勾选证书且签发成功后 HTTPS 可用；UDP 等端口不会误生成网站代理。 | R1、R2 |
| A4 | 静态目录绑定域名后内容可访问，单页应用刷新子路由可用；申请证书成功后 HTTPS 可用。 | R3 |
| A5 | 检测到较新正式版本时提醒；升级成功后版本更新、管理员仍可登录、项目和网站及证书配置保留；新版本启动失败时恢复上一版。 | R4 |
| A6 | 支持的干净系统可一键安装，管理员、密码、端口生效；未申请证书时可通过 HTTP 访问，申请成功后直接使用带配置端口的 HTTPS 地址；系统重启后服务正常。 | R6、R8 |
| A7 | 域名未正确解析或验证端口不可达时，签发失败原因可见且保留 HTTP；修正后可重试；续期后 Nginx 使用新证书。 | R1、R9 |
| A8 | 项目可启停、重启、编辑后重新部署、查看状态与日志；删除后容器和面板绑定移除，数据卷和挂载目录仍保留。 | R7 |
| A9 | 现有可用 Docker 可复用；已有外部 Nginx 或端口冲突时明确提示，原配置不被覆盖。 | R10 |

# 从编排项目打开项目目录

管理员在「容器管理 → 编排项目」打开某一行的「更多操作」，点击「项目目录」，即可在文件管理查看并操作该项目的文件。

## 实施范围

使用项目列表接口已有的 directory 字段作为目标绝对路径。通过 Vue Router 的 query 传给 /server/files，文件管理首次加载时使用指定路径。沿用现有的文件列表接口、面包屑和错误提示。

## 验收

- 分别从两个项目打开「项目目录」，文件列表和面包屑均指向所选项目；覆盖含中文、空格的路径和使用 ID 目录的旧项目。
- 浏览器返回后可回到编排项目列表，直接从侧栏进入文件管理仍默认打开根目录。
- 目标目录无法访问时显示现有错误提示，点击重试将重新读取同一目录。

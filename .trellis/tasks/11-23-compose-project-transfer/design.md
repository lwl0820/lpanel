# 设计

- 使用 ZIP，以项目元数据记录名称，项目文件放入单独的目录，保留相对路径、空目录与可执行位。导出按项目登记的实际目录读取，兼容旧项目的 ID 目录。
- 增加需登录的项目导出和导入接口。导入到独立目录，限定解包路径在该目录内；目标名称或目录被占用时返回冲突。遇到不能安全还原的条目时明确报错，避免静默遗漏文件。
- 文件就位后复用现有 Compose 校验、项目登记和 project_deploy 后台操作。登记前的失败撤销本次导入；登记后的部署失败沿用现有可重试行为。新服务器使用自己的项目 ID 和目录。
- 复用 /projects 和 /images 及现有视图，统一侧栏选中项和页内标签导航。保留 /projects?new=1。

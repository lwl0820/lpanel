# 时区与时间同步

## 首版范围

管理员能查看服务器当地时间和时区、更换时区、开关自动校时，并通过「立即同步」主动发起一次网络校时，无需等待下一轮自动同步。单次操作不改变时区或自动校时开关。页面区分自动校时设置、服务器实际同步状态和本次操作结果。首版暂不规划手动输入日期时间或自选校时服务器。

## 验收标准

- [ ] 浏览器与服务器处于不同时区时，显示服务器当地时间；切换服务器时区后刷新，时区和时间均与服务器一致。
- [ ] 启用自动校时后重新进入页面，能看到服务器实际的开关和同步状态；已启用但尚未同步时不显示为已同步。
- [ ] 关闭自动校时后刷新，开关状态与系统一致，已选的时区不变。
- [ ] 在自动校时关闭的隔离服务器上点击「立即同步」，本次校时成功后，服务器时间与校时源一致，页面显示本次同步成功；原时区和自动校时开关不变。
- [ ] 校时源不可用或系统尚未确认本次同步时，不显示本次同步成功；失败时说明原因。

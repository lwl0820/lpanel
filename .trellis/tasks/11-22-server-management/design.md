# 服务器管理设计

管理的是已登录管理员所在的单台宿主机。「服务器管理」作为独立导航入口，不混入管理登录地址、证书和升级的「面板设置」。在该入口下按功能切换，桌面和移动端均沿用现有导航；不为尚未交付的功能显示空按钮。

监控从现有首页直接进入：概览只取整机摘要；详情按时间范围读取历史样本，并可查看实时进程列表和各磁盘明细。整机历史采样由面板服务驱动，不依赖页面刷新。监控读取失败只影响监控区域，不参与首页现有项目、网站和证书数据的成组加载。

在 `internal/panel` 按功能注册 `/api/v1/server/` 下的接口，读写均沿用 `App.RequireAuth`。页面通过对应的类型化 API 模块提交具体操作，不提供通用命令执行接口。普通文件操作使用文件系统，系统服务操作复用 `App.Command`；HTTP 请求之外仍需等待的操作可复用现有操作编号和轮询。界面显示回读的系统状态，不以面板记录替代实际状态。

沿用现有 Debian、Ubuntu 支持目标。安装流程目前没有约定统一的防火墙、校时或 DNS 管理程序；实现时在目标系统识别实际配置归属，记录验证过的组合。不能判断有效配置时不报告成功，也不擅自接管其他服务。升级面板本身不得触发宿主机设置变更；还原程序版本不等于还原用户主动完成的系统修改。

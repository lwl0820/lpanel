# 服务器管理

## 目标与现状

让已登录的管理员从面板维护安装 LPanel 的这台服务器，不必为了日常文件操作或查看、修改系统设置而切换到终端。现有「面板设置」针对面板自身；本次管理的是宿主机，不是某个容器或浏览器。沿用项目已有的 Debian、Ubuntu 目标环境和单管理员登录方式。

## 已确认的任务范围

| 子任务 | 管理对象 |
| --- | --- |
| [文件管理](../11-22-server-files/prd.md) | 从宿主机根目录 `/` 管理整台服务器的文件，不限于已登记的网站和项目目录 |
| [防火墙管理](../11-22-server-firewall/prd.md) | 可启停本机防火墙并管理入站规则。启用时只自动保护当前面板对外端口，不提示或自动放行 SSH；不修改云安全组 |
| [交换空间设置](../11-22-server-swap/prd.md) | 逐项列出所有来源的 SWAP。交换文件可新建或按项删除，交换分区只读展示，不做分区管理 |
| [时区与时间同步](../11-22-server-time/prd.md) | 更换服务器时区、开关自动校时、查看同步状态，并可点击「立即同步」发起一次校时 |
| [服务器 DNS 设置](../11-22-server-dns/prd.md) | 查看、修改和恢复整台服务器默认使用的一组 DNS 地址，不按网卡配置，不修改公网域名记录 |
| [服务器状态监控](../11-22-server-monitor/prd.md) | 首页查看整机摘要；整机 CPU、内存和各磁盘空间占用每分钟采样，保留 30 天。进程 CPU、内存和磁盘读写速率仅实时展示 |

六个子任务独立验收。此任务只管理安装面板的本机，不提供多机管理或在线终端。

## 整体验收标准

- [ ] 管理员登录后能找到六项功能；未登录不能读取管理数据或执行修改。
- [ ] 五项管理功能至少走通一次「查看现状、修改、重新打开核对」；显示值与隔离服务器上的实际结果一致，不以表单提交成功代替生效。
- [ ] 只读监控单独验收：首页可进入详情，能定位当前占用资源的进程，也能回看无人打开页面时的整机负载，并与对应时段的宿主机数据核对。
- [ ] 操作失败时，界面说明哪项修改未成功，并能重新查看当前状态。已有网站和容器项目的管理入口仍可用。
- [ ] 系统设置只在隔离环境验收，交付记录注明实际验证的发行版及未覆盖的环境。

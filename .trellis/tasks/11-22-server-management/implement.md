# 实施顺序与整体验收

1. 先交付文件管理及「服务器管理」导航。其余设置模块只依赖该共用入口，彼此无依赖。每次只激活、实现和核对一个子任务，不激活主任务代替子任务。
2. 依次接入防火墙、交换空间、时区与时间同步、DNS。各子任务分别记录定向检查和隔离服务器实测结果；未实测的环境注明待验收，不以命令替身代替。
3. 监控子任务从现有首页进入，可独立交付。按[监控实施清单](../11-22-server-monitor/implement.md)核对实时进程读数、后台分钟采样、30 天清理和历史断点，不持久化进程数据，不执行系统配置修改。
4. 最后按主需求核对登录限制、桌面与移动端入口、六项功能的实际结果。运行 `npm --prefix web run typecheck` 和 `npm --prefix web run build` 核对整合后的页面。Go 测试范围及命名见子任务；缓存与临时目录按仓库 README 放在 `.tmp`。
5. 交付前核对哪些操作会直接改变宿主机。回退单个模块时撤下其页面和接口，不撤销用户已完成的系统管理操作；隔离测试机用例按各自实施清单恢复环境。

# 文件管理

## 已确认的目录范围

已登录的管理员从宿主机根目录 `/` 进入文件管理，能够浏览和读写整台服务器上的普通文件，包括系统配置文件。无需先将目录登记为网站或容器项目。面板服务以 root 运行，文件操作会直接作用于宿主机。

## 首版操作

管理员能浏览目录、创建文件夹、上传和下载文件、编辑文本、重命名及删除。首版暂不规划压缩解压、权限编辑或在线终端。

## 验收标准

- [ ] 在隔离服务器上打开文件管理，起点为 `/`；能从这里进入未登记为网站或项目的目录，再返回根目录。
- [ ] 在上述未登记目录中新建验收专用文件夹，上传文本文件后重新进入，能下载内容相同的文件。
- [ ] 编辑并保存该测试文件，重命名后在宿主机核对新文件名及内容；删除后刷新，文件不再出现。验收不改动已有系统配置文件。

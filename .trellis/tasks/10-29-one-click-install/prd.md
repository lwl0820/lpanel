# 一键安装与面板 HTTPS 初始化

## 目标与需求
落实总任务 R6、R10，集成 R8、R9。在 Debian/Ubuntu、amd64/arm64 上安装 Go 二进制及 systemd 服务，Nginx/Docker 在宿主机运行。

交互配置管理员、隐藏输入密码、面板端口及可选域名/自动证书；默认端口 8443，签发成功后直接提供 https://域名:端口。复用可用 Docker；非面板 Nginx 或端口冲突时提示并停止相关步骤，不覆盖旧环境。

## 验收条件
- 支持的干净系统完成安装，账号密码和端口生效；重启服务器后服务可用。
- 不申请证书可通过 HTTP 访问；申请成功后无需手工调整即可通过实际 HTTPS 地址访问。
- 签发失败明确输出原因和当前 HTTP 地址，不误报 HTTPS 成功。
- 复用已有可用 Docker；Nginx/端口冲突时原配置未改写。
- 脚本重跑不覆盖管理员和业务数据；密码不进入终端回显或进程参数。

## 依赖与范围
依赖基础框架、域名证书、项目、静态网站和升级产物，最后进行全链路集成。具体系统验证矩阵遵循父设计。首版不迁移其他面板、不接管外部 Nginx、不自动放行云安全组。

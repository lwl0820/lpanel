# Nginx 域名绑定与自动证书技术设计

以[总任务设计](../10-29-server-management-panel/design.md)为跨模块契约，本文件明确子任务负责范围。

## 统一模型与接口
采用父设计的域名绑定实体：资源种类和标识、目标、协议、自动证书标志、证书状态与到期时间。域名唯一；面板、项目和静态网站复用同一套 Nginx 生成、证书申请及状态查询，不复制三个实现。

## 配置生效流程
先写受管理的 HTTP 配置，统一 ACME webroot 放行验证路径；调用 Certbot certonly --webroot。成功后引用 data/acme 的证书并切换 HTTPS，执行 nginx -t 与 reload，只有完成才更新已启用状态。失败恢复面板拥有的旧配置，首次签发失败继续 HTTP。

面板证书验证始终使用独立的公网 80 路径，即使面板监听 8443。切换后在界面和安装输出中给出带端口的实际 URL。业务域名在 HTTPS 成功后可将普通 HTTP 请求跳转至 HTTPS，验证路径保持可用。

## 续期
用单个 systemd timer 运行 Certbot renew，并用部署钩子重载 Nginx；记录失败与证书实际到期时间。此 timer 的安装产物由本任务定义，安装子任务负责启用。首版不引入 ACME 库或 DNS 密钥管理。

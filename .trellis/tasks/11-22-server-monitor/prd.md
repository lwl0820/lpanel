# 服务器状态监控

## 目标

管理员能从首页判断服务器当前哪种资源吃紧，从详情查到占用空间的磁盘或消耗资源的进程，也能回看过去一段时间的资源变化。监控对象是整台宿主机，不限于面板部署的项目。

## 首版范围

- 首页概览增加资源摘要：整机 CPU 使用率、已用内存与总量、系统盘已用空间与总量。保留现有项目、网站和证书待办；从摘要可打开独立的「服务器监控」详情页。
- 详情按已挂载的本地磁盘文件系统分别展示挂载位置、已用空间、总容量和使用率。磁盘容量与进程读写速率分开显示。
- 实时进程列表展示进程名、进程号、CPU 使用率、占用的常驻内存，以及磁盘读取、写入速率。可按 CPU、内存、读速率或写速率排序。首版不记录进程历史，包括占用最高的进程；也不提供结束进程、修改优先级或执行命令的入口。
- 页面打开时自动刷新，标明最近采样时间。速率代表相邻采样之间的变化，不是自进程启动以来的累计值。没有足够数据时显示暂不可用，不把未知当成零。
- 面板服务运行期间，无论页面是否打开，每分钟记录一次整机 CPU 使用率、内存占用和各本地磁盘空间占用。详情页可选取最近 30 天内的时段查看趋势；超过 30 天的样本自动清理。没有采样的时段留空，不画成零占用。一分钟是历史采样间隔，不是实时列表的刷新间隔。

## 验收标准

- [ ] 在隔离服务器上，将首页 CPU 和内存与同一时段的系统读数比较；首页仅显示系统盘摘要，进入详情后可分别核对系统盘与数据盘的空间。没有部署项目时仍能看到宿主机指标。
- [ ] 使用可辨识的负载进程，按 CPU、内存、磁盘读或写速率分别排序，能按进程号定位对应进程。持续写盘后停止写入，进程仍存活时，其写速率随下次完整采样回落，不能显示成累计写入量。
- [ ] 进程在两次刷新之间退出时，下一次刷新后从列表消失；首次采样尚无速率时不显示为零。监控暂不可用不影响首页原有内容。
- [ ] 未登录不能获取整机或进程数据。监控操作不更改进程或系统配置。
- [ ] 关闭所有浏览器页面，在隔离机上制造一段跨越多个采样点的 CPU 或内存负载并记录起止时间。结束负载后打开详情选择该时段，能看到对应指标升高和回落；重启面板服务后，仍能查到保留期内的样本。
- [ ] 在实时列表中查看负载进程后回看同一时段，历史样本仅含整机和磁盘指标，没有进程快照、进程排名或按进程记录的占用数据。
- [ ] 连续运行期间每分钟产生一个带时间戳的样本；停止服务数分钟再启动，图上保留该段空白。对照保留期限两侧的样本，清理后最近 30 天内的记录仍可查询，过期的整机和磁盘记录均已移除。

# 实施与验证

1. 在现有项目和程序绑定接口读写 `http2` 偏好。复用 `nginx -V` 检查，在配置生成时按版本写入对应指令，并供弹窗查询能力。
2. 在共用绑定弹窗加入开关，覆盖新建默认、编辑回显和旧版提示。验证绑定接口的省略和显式关闭、Nginx 语法分支、未确认模块时保留现有 HTTPS，以及其他入口配置范围。
3. 在仓库 `.tmp/` 下准备隔离环境，用支持旧式语法和新版语法的两个 Nginx 版本分别执行 `nginx -t` 和真实访问测试。配置内同时放入两个 HTTPS 反代域名、一个共用端口的静态站点以及一个 HTTP 域名，使用测试证书和有可识别响应的本地上游。
4. 使用 `curl --http2` 和 `%{http_version}` 核对真实响应协议和内容。关闭一个绑定后检查两个域名，再复验 HTTP/1.1、WebSocket 握手 `101`、共享端口站点、HTTP 跳转和 ACME 验证路径。使用浏览器核对绑定弹窗中的开关、回显及旧版提示。
5. 对预先保存的 HTTPS 绑定通过 `setup-nginx` 重新加载配置，再核对实际 HTTP/2 响应。复用配置检查失败后恢复旧文件的回归测试。更新安装文档，说明已有绑定的启用方法，记录实测的 Nginx 版本及验证范围。

# 面板登录入口校验

## 目标

管理员可为面板设置一个专用登录地址。匿名访问其他面板地址时，服务器直接返回 HTTP 404。管理员登录后可照常访问面板首页及其他页面。

## 范围

- 在「面板设置」的访问设置中，管理员可设置、更换或清空登录路径，并看到可复制的完整登录地址。保存后当前有效会话继续使用。
- 文本框可填写以 `/` 开头的路径，如 `/abcdef`。路径区分大小写，按路径精确匹配。路径段支持英文字母、数字、短横线和下划线，系统保留路径不可占用。留空或填 `/` 表示关闭校验，使用 `/` 登录。
- 一键安装提供相同设置。交互直接回车默认留空，无人值守可通过 `--login-path` 指定，省略该项仍可按原有方式安装。安装结果输出包含设置的路径，HTTP、HTTPS 和证书申请失败后的 HTTP 地址都按此规则输出。
- 入口校验和已有用户名、密码、会话校验同时生效。公开的证书验证文件、本机自检以及独立的业务站点继续按原用途提供服务。

## 验收标准

- [x] 默认安装、显式传空值和已有无此字段的配置，都可通过根地址打开登录页。原有无人值守参数组合可以继续使用。
- [x] 配置 `/abcdef` 后，匿名访问该地址可打开登录页并用账号密码登录。请求 `/`、`/settings`、`/abcdef/`、`/ABCDEF` 或旧登录接口均直接返回 HTTP 404，响应不提供正确路径或登录页。
- [x] 登录成功后可经 `/` 进入概览，直接打开或刷新 `/settings` 等面板页面不再需要登录路径。注销或会话过期后，访问普通地址再次返回 404。
- [x] 管理员通过设置更换入口后，当前会话仍有效。新的入口立即可登录，旧入口匿名访问返回 404。重启服务保留配置。清空入口后，匿名访问 `/` 恢复显示登录页。
- [x] 安装自检使用实际入口验证页面。分别检查默认、定制路径和无交互安装，最终地址包含正确的协议、主机、端口和路径。启用入口校验时，ACME HTTP-01 仍可读取挑战文件。

## 范围之外

- 每个用户分别设置登录入口、修改业务站点路径或改动现有账号和会话规则。

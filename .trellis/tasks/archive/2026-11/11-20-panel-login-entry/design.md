# 面板登录入口设计

## 现状

- [`Config`](../../../internal/panel/config.go) 保存安装设置，[`cmd/lpanel/main.go`](../../../cmd/lpanel/main.go) 的 `init` 写入配置。现有配置文件缺省字段可继承默认值。
- [`domains.go`](../../../internal/panel/domains.go) 由 Nginx 提供前端并将 `/api/` 转到 Go。面板 SPA 目录存在 `index.html` 回退，前端根据登录状态渲染页面。当前只有在 Go API 中才检查真实会话。
- [`AccessPanel.vue`](../../../web/src/components/AccessPanel.vue) 展示面板访问地址，已登录用户通过 `/api/v1/system/access` 读取设置。[安装脚本](../../../deploy/install.sh) 从外部面板端口检查 API 与首页，[升级工作进程](../../../internal/panel/upgrade_worker.go) 从后端回环端口检查版本。

## 保存与访问

1. 在现有配置保存 `login_path`，用同一规则校验安装初始化和面板更新。空值兼容旧配置。已登录的访问设置接口提供当前值及修改操作，保存入口时保留证书和访问设置的其他字段。涉及 Nginx 配置变更时沿用既有检查、重载和回读流程，确认成功后更新设置，失败时保留原入口。
2. 打开入口校验时，由 Nginx 将面板页面交给 Go 检查路径及有效会话。复用现有会话验证逻辑。匿名可对精确入口执行 `GET` 查看登录表单及 `POST` 提交账号密码，登录页需要的资源从该入口路径下加载。其余面板页面和 API 直接返回 HTTP 404。会话有效时使用现有面板路由、静态资源和 API。仅调整面板虚拟主机，保留业务站点和 ACME challenge 位置。面板有 HTTP 跳转 HTTPS 的监听时，匿名访问错误路径也先返回 404。
3. 入口模式下，登录页载入时保留当前登录路径供表单使用。登录成功后进入根路由；普通路由退出登录后重新向服务器请求页面，使入口规则再次生效。面板已登录页面显示完整登录地址，域名或证书变更提示沿用同一配置补上路径。Nginx 跳转仍基于面板协议与主机生成，保留请求路径。
4. 安装脚本只在输入非空入口时向 `init` 传新参数。选择旧发行包且请求定制入口时，在安装写入前提示使用支持该功能的发行包。安装分别核对本机 Go 健康接口及经 Nginx 的实际登录页；原有升级探针继续使用回环端口。配置回读标识用于本机探测。

## 兼容与恢复

- 未启用入口校验时沿用原来的页面与登录 API。升级已有安装后，只有管理员保存专用入口时才切换面板路由规则。
- 安装说明记录入口格式以及忘记入口时在服务器上读取或清空配置、重新生成 Nginx 配置并重启面板的方法。

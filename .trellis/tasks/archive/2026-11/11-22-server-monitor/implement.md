# 服务器状态监控实施清单

- [x] 从现有首页接入独立监控详情，无其他子任务依赖。先完成鉴权的实时摘要、磁盘和进程读数，再接入排序与刷新；监控读取失败时保留首页原有内容。
- [x] 新增 SQLite 整机历史存储、服务生命周期内的分钟采样、按时段查询和 30 天清理。按实际时间绘图，进程计数只用于实时计算，不建进程历史表。
- [x] 聚焦速率换算、首次读数缺失和保留边界，运行 `go test ./internal/panel -run '^TestServerMonitor'`（对应实现时新增的用例）、`npm --prefix web run typecheck`。用临界时间两侧的样本验证清理，测试不等待 30 天。
- [x] 在隔离机对照系统读数与实时页面。关闭页面后制造持续数分钟的可识别负载，回看同一时段；重启面板，检查旧样本仍在、停机处断线、历史中无进程信息。浏览器核对首页待办和移动端监控入口。
- [x] 验收仅采集监控数据，不修改宿主机配置；若回退此模块，撤下入口和接口并停采，保留用户已有监控记录。

后台分钟读数、服务重启、保留期限两侧的样本以及真实浏览器结果见[监控验收记录](../../../../../docs/validation.md#服务器状态监控2026-11-22)。

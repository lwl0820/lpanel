# 编排项目升级镜像

## 目标

用户从编排项目列表更新指定项目的镜像，并让运行中的服务使用更新后的镜像。

## 操作与范围

项目行的「更多」菜单增加「升级镜像」。点击后立即提交后台操作。按该项目当前配置的标签或摘要强制拉取镜像，即使本地已有同名镜像也检查仓库。镜像版本选择由现有 Compose 配置决定。

## 验收条件

- [x] 操作只作用于所选项目。用户能从现有操作进度看到结果，失败时能看到原因。
- [x] 拉取成功后，使用旧镜像的运行中服务自动重建并使用新镜像。已使用相同镜像的服务保留原容器。
- [x] 混合运行状态的项目中，已停止的服务保持停止。整个项目已停止或尚未启动时，只拉取镜像。
- [x] 拉取失败时，运行中的容器继续提供服务。
- [x] 服务重建导致发布端口变化时，已绑定域名跟随新端口。原有固定上游仍按保存的地址转发。

镜像更新导致的容器重建可能短暂中断该服务。

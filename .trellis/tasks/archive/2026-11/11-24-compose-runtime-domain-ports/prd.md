# 绑定域名时自动发现编排项目的运行端口

## 目标

管理员从项目页或「域名与证书」选择运行中的编排项目后，可以直接选择该项目的端口绑定域名。host 网络项目无需先编辑项目、登记端口和重新部署。

## 需求与验收

- 打开绑定弹窗或切换项目时读取该项目的运行状态。普通项目展示服务名、容器 TCP 端口和当前实际发布的宿主机端口。动态分配时显示实际值；重新部署分配新端口后域名仍可访问。
- host 网络项目展示所属容器进程实际监听的 TCP 地址和端口。用一个无 ports 声明、由容器子进程监听 8080 的 Web 服务验证：选择发现的端口并绑定后，经 Nginx 访问域名应返回该服务的内容。并行运行的另一项目和宿主机进程监听的端口都不得列入该项目。
- HTTP 或 HTTPS 由用户选择。扫描结果只生成候选，用户确认后创建绑定。host 绑定保存所选地址和端口；应用改用另一端口时可重新选择并绑定。
- 无运行容器、无候选、读取失败应有对应提示。两处入口均保留手动端口，发现失败时已保存的自定义端口仍可绑定。切换项目后只展示所选项目的候选。
- 镜像 EXPOSE 与 Compose expose 只表示声明，不足以作为运行时监听证据。编排编辑页继续提供部署前的配置扫描。此任务不包含协议猜测、域名或 DNS 自动发现、为未发布的桥接端口添加映射。

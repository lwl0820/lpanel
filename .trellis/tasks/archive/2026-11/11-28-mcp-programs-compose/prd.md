# 补齐 MCP 程序管理与 Compose 项目创建

让持有有效面板令牌的 Agent 完成两项日常工作，并能从返回值判断结果。

- 程序管理覆盖列表、详情、登记、编辑启动设置、复制、删除、启停、重启、运行状态、监听端口和最近日志。程序入口使用已有的程序文件。Supervisor 的安装留在管理员界面。
- Compose 支持创建项目，跟踪该次自动部署，并用现有工具查看容器状态和日志。保留配置已保存但部署未能发起的提示。
- 更新 docs/mcp-capabilities.md，将发布基线、当前代码新增工具以及其余缺口区分清楚。其他功能只作盘点，本次范围不含通用终端和外部站点连通性检测。

## 验收

- [x] 通过 MCP 创建隔离测试项目，取得项目 ID 和部署结果；构造部署失败，能够读到终态与原因。
- [x] 通过 MCP 管理测试程序，使用预先放置的入口文件完成启停、状态与日志读取；空日志和 Supervisor 未就绪均能返回。
- [x] 入口关闭或令牌撤销后无法调用新增工具。清单中的工具名称与 tools/list 一致。

# 面板命令行管理工具

## 目标

通过安装脚本部署 LPanel 后，管理员可在服务器终端管理账号和面板访问设置。忘记密码、忘记登录入口或无法通过当前地址访问网页时，可以从终端恢复访问。

## 背景

- 现有 `lpanel` 程序提供 `init`、`bind-panel` 和 `setup-nginx` 等部署命令。`init` 只创建初始管理员。 [命令入口](../../../../../cmd/lpanel/main.go) · [管理员账号](../../../../../internal/panel/auth.go)
- 未绑定域名时，安装器提供服务器 IP 的 HTTP 访问地址。现有面板域名绑定和自动证书流程只接受普通域名。 [安装说明](../../../../../docs/install.md#域名与-https) · [域名与证书](../../../../../internal/panel/domains.go)
- 网页可以修改登录入口。现有终端恢复办法需要编辑配置、重载 Nginx 并重启面板。 [登录入口说明](../../../../../docs/install.md#专用登录入口)

## 需求

- 安装完成后提供可直接运行的管理命令和中文用法说明。命令凭服务器上的管理权限执行，无需网页会话或旧密码。
- 可以分别修改现有管理员的用户名和密码。交互式输入新密码时隐藏并确认，密码不进入命令参数或输出。密码重置成功后，已有会话需重新登录。
- 可以设置面板访问域名或 IP，也可以恢复使用服务器 IP 的默认访问方式。这里的 IP 是面板访问地址。
- 域名和 IP 访问均支持开启或关闭 HTTPS。域名证书沿用现有证书账户。公网 IPv4 和 IPv6 的证书由面板通过 Let’s Encrypt 自动申请及续期。开启时，证书须与当前访问地址匹配，HTTPS 确认可用后才报告成功。
- 公网 IP 证书的申请、安装和续期由 LPanel 内置功能完成，无需另外安装或升级证书工具。首次使用 Let’s Encrypt 时由管理员确认服务条款。公网验证失败时提示原因及处理方式。
- 可以修改对外面板端口、设置专用登录入口，或恢复从根路径登录。沿用现有端口和登录路径校验规则。
- 访问设置成功后显示完整登录地址，包含协议、域名或 IP、端口和入口路径。设置失败时说明原因，保留此前可用的访问设置。

## 验收标准

- [ ] 通过安装脚本部署后，可以从服务器终端打开管理命令的帮助并执行支持的操作。
- [x] 可独立修改用户名或重置密码，然后用更新后的凭据登录。对应旧凭据失效，重置密码前的会话失效。密码未显示在终端或命令参数中。
- [x] 可在域名访问和 IP 访问间切换。修改端口或专用入口后，命令输出的新地址可以打开登录页。清除专用入口后可以从根路径登录。
- [ ] 分别为域名、满足签发条件的公网 IPv4 和公网 IPv6 开启 HTTPS，浏览器校验证书后可打开对应登录入口。IP 签发在系统 Certbot 版本低于 5.4 时也可完成。关闭后可以通过 HTTP 登录，面板重启后仍按已保存的设置访问。
- [ ] IP 证书到期前由定时器续期，Nginx 加载续期后的证书。续期失败时记录原因并继续使用当前证书。
- [x] 无效端口或路径、端口被占用以及证书启用失败等情况会得到可理解的错误，原登录地址仍可访问。已有网站和项目的访问行为保持正常。

本地已核对管理命令帮助、IPv4 和 IPv6 登录、ACME 申请和续期协议，以及实际 Nginx 的切换和回退。公网签发、信任链和真实 systemd 安装环境列入人工验收。 [验证记录](../../../../../docs/validation.md#面板命令行管理与-ip-证书2026-11-21)

## 范围之外

- 服务器网卡、系统 IP、DNS 解析、防火墙或云安全组的修改，以及业务站点的域名和证书管理。
- 内网 IP 的 HTTPS、自签证书、手工导入证书和迁移普通域名的签发工具。

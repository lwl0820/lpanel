# 文件管理增强：批量操作、权限和分片上传

## 目标

管理员能在宿主机文件管理页一次处理多个条目，在目录之间复制或移动文件，调整权限和所有者。管理员也能把本机文件直接拖入或粘贴到当前目录，并看到大文件的上传进度。

## 需求与验收

| 功能 | 可观察的验收结果 |
| --- | --- |
| 批量删除 | 在列表中勾选多个条目，一次确认后删除所选项。未选项保留。遇到无法删除的条目时，管理员能分辨哪些已删除、哪些失败。 |
| 复制、剪切和粘贴 | 单选或多选后执行复制或剪切，进入另一目录后仍能粘贴。复制后两处都能找到内容相同的文件。剪切后源文件保留到粘贴成功，成功后只在目标目录出现。 |
| 权限和所有者 | 可以查看并修改单个条目的权限和所有者，也可以一次修改多个所选条目的权限。刷新后显示的值与宿主机实际状态一致。仅改权限时保留所有者，仅改所有者时保留权限。 |
| 拖动上传 | 从本机把文件拖入已打开的文件管理目录，松开后立即开始上传。完成后文件出现在松开时所在的目录，下载内容与源文件一致。 |
| 本机粘贴上传 | 在本机文件管理器复制一个或多个文件，回到面板当前目录按 Ctrl+V 或 ⌘V，立即开始上传。即使面板中已有待粘贴的服务器条目，本次也只上传本机文件。在文本编辑框粘贴文字仍可正常编辑。 |
| 分片与进度 | 点选、拖入和本机粘贴共用分片传输。在单次请求体大小受限的代理后，大小超过该限制的文件也能上传成功，每个分片请求均在限制内。上传期间可见进度，文件完整保存后才显示成功。 |

## 现有行为与兼容约束

- 现有目录列表和操作作用于宿主机，由已登录管理员使用。单项删除支持普通文件、符号链接本身和空目录。批量删除沿用这一范围。
- 现有上传入口一次选择一个文件，整文件作为一个请求体发送。上传同名文件时保留原文件。新上传入口沿用此行为。
- 对照位置为 `web/src/views/ServerFilesView.vue`、`web/src/server-files-api.ts`、`internal/panel/server_files.go` 和 `.trellis/spec/backend/server-files.md`。

本次上传的对象为文件。整目录上传和关闭页面后续传留待后续需求。

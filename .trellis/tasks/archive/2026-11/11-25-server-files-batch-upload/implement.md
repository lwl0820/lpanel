# 实施与验收

1. 扩展 `internal/panel/server_files.go` 的条目属性和管理员文件操作，在 `web/src/server-files-api.ts` 对齐权限、所有者、复制、移动和逐项错误契约。
2. 在 `ServerFilesView.vue` 接入多选、单行菜单、批量操作、属性修改和跨目录粘贴。用混合成功与失败的选择验证结果，与宿主机实际文件、权限及所有者核对。
3. 加入分片接口，验证同名文件、零字节文件和传输中断。将点选、拖入与本机粘贴接入同一队列，显示文件名、上传进度和结果。
4. 运行相关后端测试 `go test ./internal/panel -run TestServerFiles`、前端类型检查 `npm --prefix web run typecheck`，对涉及的前端文件运行 ESLint。回归原有编辑、上传与删除。
5. 在仓库 `.tmp/` 下建源目录和目标目录。通过单次请求体限制为 1 MiB 的代理上传超过该限制的文件，检查每个请求的大小、过程中进度的变化及最终下载的文件摘要；在空目录中也验证拖入和粘贴。
6. 用真实桌面文件管理器复制具名文件，在浏览器用 Ctrl+V 或 ⌘V 粘贴到面板，核对文件名与内容，并记录实测系统及浏览器。分别验证面板已有待粘贴项、一次粘贴多个文件、编辑器粘贴文本；模拟事件仅用于补充自动化覆盖。
7. 逐条核对需求验收表，按实测结果更新宿主机文件接口规范。后端接口与新页面配套发布；回退按设计所列顺序执行。

文件管理回归、生产构建、Linux Dolphin 与 Chrome 的真实粘贴、受限 Nginx 代理分片上传、跨盘移动与客体 root 属主变更均已通过。[项目验收记录](../../../../../docs/validation.md#文件管理批量操作与分片上传2026-11-25)

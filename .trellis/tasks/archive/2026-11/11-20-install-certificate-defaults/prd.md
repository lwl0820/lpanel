# 调整安装脚本证书交互默认值

## 需求

填写面板域名后，自动申请 HTTPS 证书和同意证书服务条款均默认选 `y`。申请证书时，联系邮箱默认使用 `acme@<面板域名>`，按回车接受。邮箱使用脚本转成小写后的完整面板域名。

域名留空时使用服务器地址，跳过证书交互。IPv4 地址沿用无效域名提示，避免把它用于证书邮箱。保留证书各项的显式选择和现有参数行为，包含 `--auto-cert n`、自定义邮箱和 `--email ''`。省略所需配置时仍需交互读取，输入结束时报告缺项。

## 验收

更新安装脚本帮助和安装说明。调整现有混合安装冒烟用例，填写域名后连续按回车，核对证书申请参数含同意条款和默认邮箱。复用现有服务器地址及显式空邮箱场景。

# 实施与验证计划

1. 在 internal/panel 核对数据库初始化、管理员设置接口、servePanel 入口过滤与代理配置。加入开关、令牌签发与撤销，验证旧库升级、重启及撤销后的下一次请求。
2. 接入远程 MCP 路由，验证客户端初始化和工具发现。逐项映射需求表中的操作，对复用的文件、容器、站点、绑定及证书逻辑保留现有接口行为。
3. 在 web/src/views/SettingsView.vue 增加开关、连接地址、具名令牌列表、签发与撤销操作。签发时说明令牌拥有所有 MCP 工具权限。
4. 在仓库 .tmp 下准备临时文件、缓存与测试资源。运行针对改动的 Go 测试（go test ./internal/panel -run 'MCP|受影响用例名'，执行前替换用例名），以及 web 下的 npm run build。核对两枚令牌权限一致、撤销隔离、重启持久化和既有管理员登录流程。
5. 从 Nginx 入口用 MCP 客户端验证四类工作流，检查面板回显和异步结果。证书测试区分受控签发结果与真实外部签发。发布和回退验收覆盖关闭 MCP 后面板原有入口仍可用。

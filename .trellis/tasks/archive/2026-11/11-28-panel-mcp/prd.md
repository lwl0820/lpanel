# 为面板增加带鉴权的 MCP 管理入口

## 目标与范围

管理员在面板设置中开启 MCP，为 Agent 签发独立令牌。每枚有效令牌拥有首版全部 MCP 工具权限。文件工具沿用面板管理员的宿主机访问范围，从根目录开始，保留各操作已有的文件类型、大小及删除限制。

| 模块 | 首版工作流 |
| --- | --- |
| 文件管理 | 浏览目录、读取和修改文本、新建目录、移动和删除条目。 |
| 容器管理 | 列出 Compose 项目及容器、查看状态和日志、启动或停止指定容器。 |
| 静态网站 | 查询、创建、编辑和删除站点，设置内容目录、主机名和单页应用回退。删除站点时保留内容目录。 |
| 域名与证书 | 查询和修改域名绑定、申请证书、获取签发状态和失败原因。 |

## 访问管理

新安装和升级后默认关闭 MCP。管理员通过现有面板会话管理开关、获取连接地址、签发具名令牌并单独撤销。启用前须有有效令牌。公网连接说明使用 HTTPS，令牌通过请求头传递。令牌签发与撤销接口使用管理员会话。所有令牌可以调用表中全部工作流。用户确认首版暂缓调用限流。

## 验收条件

- [x] 管理员按设置页提供的地址和凭据连接 MCP 客户端。两枚有效令牌均能发现并调用四类工具。
- [x] 关闭入口、凭据缺失或凭据错误时，客户端无法列出工具、执行操作或查询结果。失败请求不会修改业务资源。
- [x] 单独撤销一枚令牌后，即便 Agent 已连接，其后续请求也被拒绝，另一枚仍可用。重启后开关、有效令牌及撤销结果保持一致。
- [x] 在测试资源上逐项验证上表工作流，面板能看到 Agent 的修改，后台操作可以追踪到最终结果。

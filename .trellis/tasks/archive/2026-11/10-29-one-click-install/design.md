# 一键安装与面板 HTTPS 初始化技术设计

以[总任务设计](../10-29-server-management-panel/design.md)为跨模块契约，本文件明确子任务负责范围。

## 安装步骤
root 执行，先检测系统/架构和已有环境，交互收集配置，再写系统文件。缺少的依赖通过 apt 安装；已有 Docker 验证可用后复用，冲突软件不自动卸载。安装脚本使用工作目录 .tmp 下载发行包并验证格式和校验文件，部署到 releases/current。

通过程序初始化入口从标准输入设置管理员，写入持久配置，安装主服务及证书续期 timer，启动 Nginx 与后端；域名签发通过共同证书能力完成，不能写第二套证书流程。结束前确认真实服务状态与 URL，签发失败单独报告。

## 环境与重跑
目标矩阵为 Debian 12/13、Ubuntu 22.04/24.04/26.04 LTS，amd64/arm64。识别面板自己的安装标记与布局；已有安装保留账号和数据并提示使用升级入口，不重复初始化。发现非面板 Nginx 或端口占用时停止，不自动替换配置。

## 发布与系统恢复
安装读取实际配置的发布源和固定附件契约，开发阶段支持本地发行包集成验证。只恢复本次生成且面板拥有的配置，不卸载用户软件。服务启动失败输出可定位日志，证书失败保留已可访问的 HTTP 入口。实际安装测试仅在隔离机器进行。

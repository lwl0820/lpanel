# 完善静态网站创建与备注编辑

## 目标

管理员新建静态网站时，可以一次配置所有访问主机名，直接用有辨识度的网站标识找到站点与默认网页目录，并通过备注记录网站用途。

## 现状

- 新建表单收集网站名称和一个可选域名，填写域名时可以勾选自动申请 HTTPS。编辑表单可以修改网站名称、网页目录及单页应用设置。[网站表单](../../../web/src/views/SitesView.vue#L143)
- 网站记录按内部 ID 关联域名，旧网站的名称允许重复，创建时留空的网页目录按内部 ID 分配。[网站保存](../../../internal/panel/sites.go#L161)
- 域名绑定已经支持同一网站关联多个域名，并按域名单独管理证书。现有校验接受普通域名。[域名绑定](../../../internal/panel/domains.go#L180)

## 需求与验收

1. 新建时必填主机名，可以逐行填写多个。去掉每行首尾空白并忽略空行。只有空白时提示至少填写一个主机名，填错或重复时提示相应主机名。填写两个有效主机名后，两个地址都绑定到同一个静态网站。任一绑定失败时，本次创建无需手工清理即可重试。
2. 用「网站标识」代替「网站名称」。创建时用第一个有效输入行填充，允许手动覆盖。手动填写后，继续修改主机名不会覆盖该值。已有网站使用此标识的情况下，提交时提示更换。
3. 留空网页目录时，面板按网站标识在默认网站目录下创建目录。保留标识原文，把不适合文件名或现有网站配置的字符替换成路径安全的字符。例如标识 `团队/官网` 对应目录名 `团队_官网`。默认目录已存在时，表单提示可修改标识或指定网页目录，已有内容不受影响。手动填写时使用已有的绝对目录。
4. 创建和编辑时均可填写、修改或清空备注。保存后重新打开编辑窗口，能看到已保存的内容。备注可以留空。
5. 已有网站升级后仍可访问和编辑。沿用原有目录、域名和证书；从旧名称生成网站标识，重复名称生成带后缀的唯一标识。无域名的旧网站仍可保存备注。编辑网站标识时，网页目录保持原位置。
6. 勾选自动申请 HTTPS 后，为每个普通域名独立申请证书。一个域名申请失败时，其 HTTP 入口保留，其他域名仍继续申请。页面按域名展示 HTTPS 生效情况与失败原因。
7. 静态网站支持 `*.example.com` 形式的通配符主机名。解析到服务器的匹配子域名可以通过 HTTP 访问，根域名 `example.com` 可单独添加。表单说明通配符地址仅提供 HTTP。通配符和普通域名同时填写时，仍可为普通域名自动申请 HTTPS。通配符排在首行时，默认标识为 `*.example.com`，默认目录名为 `_.example.com`。

## 范围边界

普通域名沿用现有域名校验、域名管理入口和证书流程。通配符 HTTPS、DNS 验证、IP 地址、本地主机名以及面板和容器项目的通配符绑定另行处理。

## 验收记录

- 后端网站、域名及证书定向测试与 `go vet` 通过。覆盖旧库重名迁移、默认目录碰撞、整批回滚、通配符拒绝签发以及普通域名签发部分失败。
- 前端类型检查、ESLint、18 项相关 Vitest 测试与生产构建通过。
- 在独立网络命名空间使用 Chrome 和真实 Nginx，验证必填反馈、标识默认值与手动覆盖、备注保存和清空、重复主机名冲突回滚、多个普通及通配符主机名访问同一网页，以及窄屏表单。通过本地 Certbot 替身生成测试证书，验证一个普通域名失败保留 HTTP 后，后续普通域名仍能启用 HTTPS。公网证书签发待目标环境验收。

# 实施与验证

1. 在 internal/panel 的项目路由增加归档读写，接入现有项目登记与部署流程。检查面板代理是否允许归档上传和下载。
2. 在项目列表接入导入、导出与后台部署反馈。更新侧栏、两个页面的标签导航、概览入口及相关文案。
3. 在两个独立面板数据目录之间验证导出导入往返，比较隐藏文件、嵌套数据、二进制内容、权限和空目录；验证自动提交部署、同名冲突和失败后重试。
4. 运行 go test ./internal/panel -run 'Project'，以及 web 下的 npm run typecheck 和 npx vitest run src/router.test.ts；如新增页面测试，一起运行。
5. 在浏览器核对标签切换、旧链接及新建直达。用可运行 Docker 的环境验证目标服务读取导入文件并成功启动，记录实际运行范围。

# 支持多个免费证书提供商

## 目标

安装时可以选择免费证书提供商。安装后可以同时配置多个 ACME 账户，并为每次证书申请选择账户。面板、Compose 项目和静态网站共用这些账户。

## 需求

- **安装**。选择安装时申请 HTTPS 证书后，可选 Let’s Encrypt 或 ZeroSSL，直接回车选 Let’s Encrypt。安装时填写的提供商和联系邮箱用于创建面板的默认 ACME 账户。选择 HTTP 安装时，账户列表初始为空。保留既有无人值守安装用法。
- **账户管理**。在「域名与证书」中提供「ACME 账户管理」，可查看、新增、配置和删除账户。列表显示名称、提供商和默认状态，同一提供商的多个账户可按名称区分。账户仍有已签发的证书时禁止删除，包含仍保留但已过期、换下或解除绑定的证书。界面提示删除受阻的原因。
- **默认账户**。没有账户时，首个新增账户自动成为默认。删除默认账户后，自动选一个剩余账户。删除最后一个账户后保持无默认状态，下次添加时重新建立默认账户。
- **按次选择**。申请、重试和手动续期均可选择账户。新申请预选默认账户。已有证书的操作优先预选仍可选的签发账户，否则预选默认账户。没有可选账户时提示先添加账户。改选账户只作用于本次操作。
- **证书生效与续期**。成功签发并启用后，记录证书实际使用的账户。现有证书继续使用原签发账户自动续期。换账户签发失败时保留原证书及 HTTPS。首次签发失败时保留 HTTP。
- **兼容**：升级后已有证书可以继续使用及续期。旧版已配置的自定义 ACME 地址仍可使用。未选择证书的域名绑定流程仍可直接提交。

## 验收

- 用签发替身验证安装选择 Let’s Encrypt 或 ZeroSSL 后，安装时填写的联系邮箱与所选提供商出现在面板默认账户上。首次证书申请失败后可查看该账户并重试。
- HTTP 安装后账户列表为空。添加首个账户，确认它成为默认。添加第二个账户后删除原默认，确认剩余账户成为默认。删除最后一个账户并重启，确认仍无默认。再次添加后确认恢复默认。
- 添加两种提供商的账户后，可分别为域名绑定、静态网站新建和手动申请选择不同账户。域名与证书列表能看到 HTTPS 正在使用的账户或提供商。
- 同一域名可以换账户重新签发。成功后定时续期使用新账户，失败后 HTTPS 和续期仍使用原证书对应的账户。
- 分别对仍有在用证书、以及仅有已过期或已解除绑定证书的账户执行删除，面板提示原因，账户及默认账户状态保持原样。没有证书的账户可以删除，删除成功后再按规则更新默认账户。
- 既有安装无需重新绑定域名或重新签发证书，即可完成升级后的首次续期。现有全参数安装保持可用。
- 管理接口、页面及操作日志不回显 ZeroSSL 的账户绑定密钥。

## 范围

首版支持 Let’s Encrypt 和 ZeroSSL，使用现有公网 80 端口域名验证。自动切换提供商、批量迁移已有证书、DNS 验证、泛域名、自定义提供商的新增入口和撤销已签发证书不在本次范围。

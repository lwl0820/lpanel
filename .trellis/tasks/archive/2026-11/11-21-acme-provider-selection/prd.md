# 优化 ACME 证书提供商选择与账户注册

## 目标

让管理员在「域名与证书 → ACME 账户管理」添加证书账户时，通过下拉菜单选择提供商。简化 ZeroSSL 注册，并提供 Google Cloud Public CA 免费证书。

## 需求

- R1.「添加证书账户」中将证书提供商改为单选下拉框，默认选中 Let’s Encrypt。既有账户的提供商在编辑时只读。
- R2. 选择 ZeroSSL 后，可填写联系邮箱，由面板获取账户绑定凭据并注册。保留手动填写一对绑定凭据的入口，用于自动获取失败或已有凭据的情况。
- R3. 下拉框提供 Google Cloud Public CA。添加账户时引导管理员从自己的 Google Cloud 项目获取并填写 EAB Key ID 和 HMAC 密钥。同意对应服务条款并注册成功后，可用该账户申请和自动续期证书。

## 范围

本次覆盖面板中的账户管理、HTTPS 证书申请和自动续期。安装脚本、`bind-panel` 命令、验证方式和泛域名支持属于其他流程。Buypass Go SSL 已于 2025 年 10 月 16 日停止签发和续期，因此下拉框仅列可用提供商。 [Buypass 官方公告](https://www.buypass.com/products/tls-ssl-certificates/go-ssl)

## 验收标准

- R1. 用鼠标和键盘均可选择提供商。切换提供商后显示相应的注册字段和条款链接，清除上一个提供商的凭据、条款勾选和校验提示。
- R2. 新建 ZeroSSL 账户或重试待配置的 ZeroSSL 账户时，仅凭邮箱可完成自动获取和注册。自动获取失败时提示重试或手动提供凭据，手动注册成功后账户可用于签发。
- R3. Google Cloud Public CA 缺少任一绑定字段时提示补全。成功注册后可在已有签发入口选用该账户，续期继续使用签发时的账户。注册失败的账户可在编辑时重新填写凭据。
- R2、R3. 凭据不出现在列表、接口响应、日志或命令参数中。已有证书和已注册账户继续使用原有目录和签发配置。

# 执行与验证

1. 在项目路由中加入单容器启停及归属校验，在独立镜像模块中实现列表、删除和清理。
2. 在展开的容器行接入启停，在导航加入镜像页，展示镜像名称、大小及确认操作。
3. 用 Docker 命令替身检查同服务副本选择、跨项目目标、镜像分组、普通删除和清理参数及失败回显。
4. 仅运行相关 Go 用例、前端路由测试、受影响文件 lint、类型检查及构建。用浏览器核对按钮、确认取消和刷新。验证不清理宿主机镜像。
5. 更新受影响接口契约，记录验证覆盖范围。两个入口可按功能独立回退。

## 验收结果

两项 issue 的验收条件均通过。Go 定向测试验证项目归属和镜像操作参数，8 条前端路由测试、受影响文件 ESLint、类型检查和生产构建通过。Chrome 验证桌面及窄屏交互。隔离虚拟机中的真实 Docker 验证副本启停、删除冲突及镜像清理保留范围。详细记录见仓库 docs/validation.md。

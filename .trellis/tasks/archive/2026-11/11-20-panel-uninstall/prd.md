# LPanel 一键卸载

## 目标

让通过官方脚本安装 LPanel 的管理员，可以用一条独立命令停止并移除面板，并在操作前知道哪些访问入口会失效、哪些数据会保留。

## 范围

- 新增独立的 `deploy/uninstall.sh`，适用于官方安装脚本使用的 `/opt/lpanel` 和 systemd 布局。README 提供在线卸载命令，安装文档说明其影响。
- 执行前展示影响，并要求管理员明确确认。移除 LPanel 的 systemd 主服务、证书续期服务和定时器、已安装的程序版本，以及由 LPanel 生成的 Nginx 配置。
- 面板原访问地址和依赖该 Nginx 配置的业务域名会停止服务。卸载时可选择保留 Compose 项目（默认），或同时停止并移除由当前面板部署的 Compose 容器和项目网络。
- 清理选项还会递归删除所选项目的整个目录 `/opt/lpanel/data/projects/<项目 ID>/`，包括配置文件、`.env` 和 Compose 相对路径挂载的数据，并移除这些项目在面板内的项目记录和域名绑定。最终确认前列出项目和将删除的路径，明确目录内数据会丢失。
- Docker 数据卷和镜像保留，项目目录之外的宿主机挂载目录、静态网站文件及其他 Docker 项目也保留。容器可写层中未挂载到卷或宿主机的文件会随容器删除。
- 面板数据库、管理员账号、证书、私钥和静态网站配置原地保留。选择仅卸载面板时，项目目录和所有项目记录也保留。系统软件包、Docker 服务、Nginx 服务及其他 Nginx 配置保留。
- 数据彻底清除、域名迁移和自动恢复安装由后续需求决定。现有安装脚本会拒绝覆盖旧数据及已有 Nginx，卸载说明需交代这一限制。

## 验收

- [x] 普通用户运行、取消确认，以及未安装或已经卸载的情况下，脚本不更改系统。
- [x] 默认安装正常卸载后，面板和续期单元停用，面板程序和生成的域名配置已移除，其他 Nginx 配置与保留数据不变。
- [x] 默认选项保留项目容器、网络、目录和记录。选择清理时，仅清理确认列表中的面板项目，验证容器、项目网络、项目目录（含相对挂载数据）、项目记录及其域名绑定被移除，Docker 卷、镜像、目录外的挂载数据和其他项目保留。Docker 清理失败时保留失败项目的目录及记录并提示错误。
- [x] Nginx 配置不属于 LPanel 时保留文件并提示。移除后配置检查、重载失败时恢复文件并报错，可修复环境后重试。
- [x] README 和安装文档提供一致的操作说明；本地实现验证通过后如需公布在线入口，再同步核对 GitHub 上的脚本。

# 卸载实施计划

1. 添加独立 Bash 脚本。识别官方安装及受管资源，按选择决定是否读取项目清单，展示域名中断、将删除的项目目录及数据范围并确认。按设计停用、调用 Compose、删除对应项目目录和记录、检查 Nginx 并移除面板程序。
2. 在 README 与安装说明添加卸载入口、兼容范围、域名中断、Compose 清理选项、数据保留及重装限制。
3. 运行 Bash 语法检查。在隔离容器或现有命令替身环境内验证取消、默认卸载、重复运行、可选项目目录及相对挂载数据删除、目录外挂载数据保留、Compose 失败时不删除失败项目目录、Nginx 检查或重载失败时恢复。Docker 可用时验证真实的项目容器、网络和数据卷状态。验证仅涉及卸载路径。
4. 复核差异和操作结果。推送与发布由用户另行授权。

# 融合 SupervisorPanel 的宿主机程序管理

## 目标与范围

管理员可以在 LPanel 新建并托管直接运行于 Linux 的二进制或脚本，从上传文件、启动程序到通过域名访问，均使用现有管理员账号。「程序管理」与「容器管理」并列。首版管理对象为在 LPanel 创建的程序。已有 SupervisorPanel 项目迁移明确排除在本任务之外。

## 功能与验收

| 功能 | 验收条件 |
| --- | --- |
| 程序列表与详情（B 版） | 桌面左侧列出程序及状态，右侧显示所选程序，默认打开「运行日志」，可切到「启动设置」。手机上程序选择列表位于详情上方，可横向滑动。切换到另一程序时，指标、日志、文件目录、端口和启停操作均对应当前选中项。 |
| 创建与配置 | 新建程序后获得独立工作目录。在启动设置中填写主程序相对路径、启动参数和运行用户。保存后程序处于停止状态。 |
| 使用现有文件管理 | 在详情点击「打开目录」，现有文件管理直接定位到该程序目录，可使用单文件上传、文本编辑和下载。上传二进制后，管理员能将其设为主程序并以指定用户执行。 |
| 启停与守护 | 通过 Supervisor 启动、停止和重启指定程序。手动停止后保持停止，运行时异常退出按托管配置拉起。入口或权限有误时，页面显示启动失败原因。 |
| 运行信息与日志 | 显示主进程 PID、CPU、内存、连接数及实际监听端口。在所选程序的「运行日志」中，先看到最近输出，随后能看到新行。程序停止后运行信息反映停止状态，历史日志仍可读。 |
| 使用现有域名与证书 | 从程序监听端口和「域名与证书」均可打开现有绑定弹窗，选择程序、端口、上游协议及证书账户。现有页面支持查看、编辑、解绑和续期，同名冲突有提示。使用受控域名验证 HTTPS 和 WebSocket 访问。 |
| 复制与删除 | 副本拥有独立目录和相同的启动设置，初始停止，域名继续归属原程序。删除前显示清理范围，默认保留业务文件，也可选择一并清理。其他程序、网站和容器的域名仍可访问。 |
| LPanel 版本兼容 | 从已有 LPanel 版本升级后，原编排项目、域名与证书仍可使用。主机缺少 Supervisor 时，程序页提示所需依赖，其他面板功能仍可用。 |

## 其他范围约定

整机监控、账号、校时和面板升级沿用 LPanel 现有入口。自定义 NTP 源和重启整台服务器上的 Supervisor 服务留待其他任务评估。

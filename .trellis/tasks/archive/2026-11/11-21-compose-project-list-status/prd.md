# 容器项目列表、单容器日志与文件清理

## 目标

管理员可从项目列表判断运行情况、展开容器并读取日志，也能在删除项目时按需清理留在服务器上的项目文件。

## 现状

- [容器项目页面](../../../web/src/views/ProjectsView.vue)的主列表只显示项目名称、域名、配置更新时间与操作。启动、停止和重启位于「更多操作」，容器状态和项目汇总日志在同一抽屉。
- [项目接口](../../../internal/panel/projects.go)已能读取项目内的容器状态，日志接口返回整个 Compose 项目的日志。同一服务有多个容器时，需要通过容器本身区分日志来源。
- 当前删除项目会移除项目容器、网络、域名绑定和面板记录，项目目录一直保留。

## 需求

- 项目行显示运行状态。全部运行、部分运行、未运行、暂无容器和读取失败时显示不同的中文状态，容器健康异常可从项目状态和展开明细中识别。
- 项目行可直接展开和收起。展开后在该行下方显示项目所属容器的名称、服务、运行状态和有结果的健康检查。
- 每个容器有「查看日志」入口。日志窗口标明容器名称，支持刷新最近日志。同一服务的多个副本各自显示对应容器的日志。
- 项目行直接显示「启动／停止」「重启」「编辑配置」。绑定域名、项目汇总日志和删除项目收入「更多操作」。
- 项目重新部署、启动、停止或重启完成后，更新项目行状态与已展开的容器明细。页面的「刷新」也会重新读取状态。
- 删除确认框提供默认关闭的「同时删除项目文件」。勾选时显示项目目录，并说明目录内的 Compose 配置、环境变量文件及 `./data` 等相对挂载数据会永久删除。
- 文件清理以面板记录对应的单个项目目录为界。Docker 命名卷、镜像和项目目录以外的数据继续保留。项目目录内仍有宿主机文件系统挂载点时，提示卸载后再清理。

## 验收标准

- 打开列表即可看到多种项目运行状态。个别项目状态读取失败时，其余项目和操作仍可使用。
- 展开某个项目只显示该项目的容器，收起后恢复紧凑列表。窄屏可以打开明细并点击常用操作。
- 含两个同服务容器的项目中，分别点击两者的「查看日志」，窗口标题和内容分别对应所选容器；暂无日志与读取失败有明确提示。
- 启停或保存配置触发的部署结束后，列表状态和展开内容反映实际容器状态。
- 宽屏、窄屏都可直接使用约定的常用按钮，从「更多操作」可找到其余操作。
- 取消删除时不发起操作；正常删除时保留项目目录；勾选文件清理后，项目目录和目录内的相对挂载数据被删除，目录外测试文件及命名卷保留。
- 容器和网络清理失败时，项目目录和项目记录保留。目录无法清理时显示具体失败原因，并保留项目记录供处理。

## 范围

本任务覆盖容器项目页和对应 API。继续沿用创建及保存配置自动部署，生命周期操作继续按项目执行。日志以最近记录和手动刷新为主。

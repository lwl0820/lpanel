# 补齐项目开发规范

## 目标

将 Trellis 初始化生成的项目规范补齐，后续开发可按实际源码查找目录、实现约定和验收方式。

## 范围

- 后端补齐 Go 模块目录、SQLite、错误处理、日志脱敏和验证要求。
- 前端补齐组合式逻辑、页面状态、类型和验证要求，并校对目录说明。
- 每份规范链接实际源码、测试或项目文档。后端和前端索引列出各自的实际文件。
- 使用现有 API、长操作与托管契约表达项目经验，避免从模板引入额外架构或测试要求。

## 验收

- [x] 后端和前端项目规范采用真实文件、接口和运行行为。
- [x] 建立可直接参考的 SQLite 查询与前端操作轮询示例。
- [x] 核对索引、相对链接和模板占位，保留原有的通用思考指南。

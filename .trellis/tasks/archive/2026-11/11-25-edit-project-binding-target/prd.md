# 编辑编排域名绑定的端口和上游协议

## 目标

管理员在「域名与证书 → 编辑」内修改已有编排项目绑定，保留原绑定及同域名的有效证书。例如外部仍用 HTTPS 访问，应用端可从 https://127.0.0.1:9090 改为 http://127.0.0.1:9090。

## 范围与验收

- 打开编辑窗口即可看到当前上游地址、端口和协议。端口候选限于该项目，包含 Docker 发布映射、host 服务监听及已保存的自定义端口。
- 可只改 HTTP/HTTPS、只换端口或同时修改。当前目标暂时未被发现时仍可保留它并只改协议。取消编辑保留原绑定。
- 保存后沿用原绑定 ID 并更新 Nginx。同域名已有有效证书时，保留证书、账户及到期时间，无需再次签发。验证时用原 HTTPS 域名访问，确认返回所选上游的内容。
- 新选端口失效或 Nginx 配置应用失败时给出原因，保留原绑定和代理配置。此处沿用配置生效检查；应用自身返回的 HTTP 状态由实际访问验收。
- 已发布端口继续跟随 Docker 动态映射；host 监听和手动端口继续使用固定上游。保留已有域名改名和证书设置功能。

本次只调整已有编排绑定的项目内转发目标。跨项目迁移、任意上游 URL 和新的管理页面均在范围之外。

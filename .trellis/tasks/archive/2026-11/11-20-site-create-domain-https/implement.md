# 实施计划

1. 扩展静态网站创建入口。生成默认目录，复用已有自定义目录校验。保持已存在的网站和手动指定目录可照常编辑。
2. 接入创建时的可选域名绑定、HTTP 生效确认和现有证书任务。处理绑定失败、任务未启动和证书失败，让表单与实际保存状态一致。
3. 更新静态网站新建表单、请求类型与列表刷新，复用现有域名/证书状态及中文提示。同步 README 的静态网站说明。
4. 执行受影响的 Go 网站、域名与证书测试，覆盖默认目录、手动目录、重复域名或重载失败、成功提交和证书失败保留 HTTP。运行前端类型检查、lint，并在浏览器验证新建表单可选组合与错误反馈。用测试证书或替身验证签发流程，公网 CA 结果单独记录。

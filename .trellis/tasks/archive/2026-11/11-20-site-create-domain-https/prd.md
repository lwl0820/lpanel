# 静态网站默认目录与创建时启用 HTTPS

## 目标

用户可以只填名称创建静态网站，由面板自动分配网页目录。若已有网页，可以指定服务器目录。创建时可以在同一表单填写域名并选择自动申请 HTTPS 证书。

## 范围

- 新建表单允许目录留空。面板自动创建 `/opt/lpanel/sites/<网站 ID>/`，创建后在网站列表显示实际路径。手动填写时使用服务器上已存在的绝对目录。
- 域名为可选项。填写域名时可以勾选自动申请 HTTPS 证书，未勾选时绑定 HTTP。留空时创建网站，后续可以从现有入口绑定域名。
- 域名格式无效、已被使用、勾选 HTTPS 但尚未同意证书服务条款，或 Nginx 无法应用绑定时，在表单显示原因。本次创建不能留下重复或无绑定的网站记录，已经存在的自定义目录及其文件保留。
- 域名绑定成功后，证书异步申请。申请期间显示进度，成功后显示 HTTPS 已启用。签发或启用失败时保留网站与 HTTP 入口，显示原因并允许通过现有入口重试。
- 现有网站编辑、单页路由回退和删除时保留内容目录的行为继续适用。网页文件由用户放入内容目录，文件上传和在线编辑另行处理。

## 验收

- [x] 留空目录创建成功，返回实际路径，Nginx 运行用户能访问该路径下权限合适的网页文件。不同网站的默认目录独立，名称可以包含中文。
- [x] 手动指定已有目录时使用原路径。无效路径有明确反馈，既有内容文件保留。
- [x] 单次提交支持创建无域名网站、创建并绑定 HTTP 域名、创建并开始申请 HTTPS 三种方式。
- [x] 重复域名、勾选 HTTPS 但尚未同意证书服务条款，或 Nginx 绑定失败时不留下本次网站和绑定，改正表单后可直接重试。
- [x] 证书成功后才显示 HTTPS。签发失败时已有 HTTP 仍可访问并有失败原因，修复后可重试证书，无需重复创建网站。

## 验收记录

- Go 网站、绑定、证书和 Nginx 相关测试、相关包的 go vet、前端类型检查、ESLint、17 项相关 Vitest 测试和生产构建均通过。
- Chrome 与真实 Nginx 在独立网络命名空间完成联调。验证默认/手动目录、同表单绑定 HTTP、重复域名回滚、证书申请中仍显示 HTTP、HTTPS 实际访问、签发失败保留 HTTP，以及从域名与证书重试成功。
- 证书签发使用本地测试证书与失败替身，未执行公网 CA 签发。改动保存在工作区。

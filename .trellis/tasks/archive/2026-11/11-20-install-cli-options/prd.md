# 安装脚本支持命令行配置

## 目标

安装时可预先提供部分或全部配置。脚本仅询问当前安装方式下缺少的配置。所有适用配置都已提供时，脚本可在标准输入关闭的情况下运行。

## 现状

脚本支持 `--repository` 和 `--archive`，其余安装选项通过交互读取。管理员密码从标准输入交给面板初始化命令。 [安装脚本](../../../../../deploy/install.sh) · [安装说明](../../../../../docs/install.md)

## 需求

| 参数 | 行为 |
| --- | --- |
| `--username <账号>` | 设置管理员账号，省略时保留交互提示和默认账号 `admin`。 |
| `--password <密码>` | 直接设置管理员密码并跳过密码提示与确认。省略时隐藏输入并要求确认。密码为单行，长度为 8 至 72 字节。 |
| `--port <端口>` | 设置面板端口，省略时保留交互提示和默认端口 `8443`。 |
| `--domain <域名>` | 设置面板域名。`--domain ''` 表示使用服务器地址，跳过域名和证书提示。省略时询问域名。 |
| `--auto-cert <y或n>` | 有域名时选择是否申请证书。省略时询问。申请证书必须有域名。 |
| `--agree-tos` | 显式同意证书服务条款。申请证书且省略该参数时询问。 |
| `--email <邮箱>` | 申请证书时填写联系邮箱。`--email ''` 表示留空，省略时询问。 |
| `--repository <账号/仓库>`、`--archive <路径>` | 沿用现有发布源和本地包入口。没有本地包时，按命令行、`LPANEL_REPOSITORY`、交互的顺序取发布源。 |

参数值与交互输入使用相同的校验。未知参数、缺失选项值和校验失败在安装写入之前报错。缺项需要交互而标准输入结束时，指出缺少哪项配置。

显式传入的密码值属于安装脚本的进程参数，直接键入命令也可能将密码留在终端历史中。脚本通过标准输入把密码交给面板初始化，安装输出和初始化命令的进程参数都须避免泄露密码。安装说明需解释直接传参的可见性，日志规范需明确这项边界。 [日志规范](../../../../spec/backend/logging-guidelines.md)

范围限于安装脚本的配置输入、`--help`、使用文档、日志规范和安装分支回归检查。 [安装说明](../../../../../docs/install.md) · [README](../../../../../README.md)

## 验收条件

- 使用现有 README 命令仍可完成原交互安装，账号、端口和证书选项仍提供现有默认值。
- 混合安装只读取缺项。已有参数经过同一套校验并生效。
- 用本地测试发行包验证标准输入关闭时的两种安装。显式空域名可完成 HTTP 安装，域名及证书参数齐全时可进入签发分支。证书验证使用测试替身。
- 隔离环境核对 `--password` 跳过密码及确认提示，含空格或符号的密码按原值经标准输入到达初始化命令。检查初始化命令参数和安装输出中没有密码值。空密码、错误选项或需要输入但遇到 EOF 时给出可定位的失败提示。
- `--help`、README 和安装说明包含参数和可复制的用法。验收执行脚本语法检查、安装冒烟测试。公网签发及其他缺少目标环境的验证交由人工。 [安装冒烟测试](../../../../../tests/install-smoke.sh) · [人工验收规范](../../../../spec/backend/quality-guidelines.md#本地验收与人工验收)

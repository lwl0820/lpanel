# 实施与验证

1. 在 internal/panel/projects.go 扩展项目表和记录读取，覆盖旧表回填、重复启动、旧项目重名和旧名称不合法的情形。
2. 接入路径解析和占用检查。核对运行命令、配置扫描、改名、恢复和两种删除方式，沿用原项目 ID 操作 Docker 资源。
3. 更新 web/src/views/ProjectsView.vue 的名称校验、恢复流程、删除说明，以及对应接口类型。同步 README、安装说明和托管契约。
4. 更新 deploy/uninstall.sh 的目录读取与检查。旧版数据库仍可按 ID 找到目录；新版使用记录的路径。
5. 用 go test ./internal/panel -run Project 及受影响的项目集成用例核对旧路径、名称占用、改名及同名重建。预置根目录配置、嵌套同名文件和业务数据，验证两种删除范围。运行 bash tests/uninstall-smoke.sh 和前端类型检查、构建，核对创建与删除表单。
6. 在隔离目录用旧库及已有容器验证升级，比较升级前后项目目录、挂载和容器状态。若回填失败，应保留原记录并可重试。验证记录中区分命令替身与实际 Docker 验收结果。

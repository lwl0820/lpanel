# 目录存储与操作

在 projects 表保存相对于 data/projects 的目录路径。创建时记录项目名，升级时在数据库事务中为原有记录回填项目 ID。旧版实现见提交 cb1aa30 中的 internal/panel/projects.go，第 58 行定义项目表，第 172 行计算目录。回填不需要移动目录、重建容器或重启项目。

所有路径使用者从记录解析目录，涵盖列表、扫描、保存、部署、删除和 deploy/uninstall.sh 的检查与清理。Docker Compose 运行标识继续使用 lpanel-<ID>。保留旧项目的命名模式信息，以便区分旧项目编辑和新项目改名。路径约束适用于全部已登记项目；旧显示名称可重复，新建时需查询包括旧项目在内的名称占用。

创建时将登记状态和磁盘内容分别处理。未登记目录里的业务数据原地使用；目录中已有配置时，前后端允许使用磁盘配置完成校验与部署。已有项目改名涉及两份目录内容时，不静默覆盖文件。保存和删除沿用项目目录边界与现有挂载点检查。卸载同时兼容升级前后的数据库结构。

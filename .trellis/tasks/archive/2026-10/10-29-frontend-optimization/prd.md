# 前端界面优化

## Goal

整体重新设计 LPanel 管理面板的界面，包括配色、字号、布局、导航、信息层级、各状态的呈现和移动端体验，覆盖登录、概览、容器项目、静态网站、域名与证书、面板设置所有页面。

## 已确认的决定

- 2026-10-29：用户选择整体重新设计，不只是在现有风格上修整细节。
- 先出可点击的 HTML 设计原型，用户确认后再改 `web/` 代码。
- 2026-10-29：视觉方向选“浅色简洁”：白色侧栏、浅灰内容区、单一蓝色主色、细边框，加大字号和文字对比度。只做浅色，不做暗色主题。
- 引入 vue-router：刷新后停留在当前页，支持浏览器前进/后退（来自范围选择“路由与界面调整”）。
- 2026-10-29：用户确认原型 `.trellis/tasks/10-29-frontend-optimization/research/prototype.html` 作为最终方向（截图 `.tmp/shots/proto-*.png`）。原型里的数据和操作结果是模拟的；实现时以真实接口为准，原型与现有功能冲突时保留现有功能。

- “已连接”状态在侧栏底部和页面标题右侧各显示一次，两处都是写死的，并不反映真实连接状态（`web/src/App.vue:38-39`）。

- 欢迎横幅占了首屏最显眼的位置，内容只有问候语。

- 页面没有展示任何服务器或资源数据。现有接口能取到项目、网站、域名绑定列表以及证书到期时间。

### 列表页

- 移动端表格被截断，“操作”列需要横向滚动才能看到。

### 表单与对话框

- 发布仓库输入框与“保存发布源”按钮挤在同一个表单项里，对齐方式与上方的访问设置不一致。
- 项目对话框固定 850px 宽（`web/src/ProjectsView.vue:58,60`），窄屏下会溢出。“扫描端口”与“取消”“保存”混排在页脚。

### 视觉细节
- 大量 10–12px 文字使用 `#8995a8`、`#9aa5b6` 等浅灰色，在白底上对比度偏低。
- 导航图标使用 Unicode 符号（◈ ▦ ▤ ◇ ⚙），各平台渲染不一致。
- 颜色直接硬编码在各组件的 scoped 样式中。

## Requirements

### 整体框架
- R1 配色、字号、圆角、阴影统一定义为 CSS 变量，取值与原型 `:root` 一致；Element Plus 主色等变量映射到同一套取值。正文 14px，辅助文字不低于 12px，浅灰文字不再用于正文。
- R2 桌面端：白色侧栏（品牌、5 个导航项、底部账号与退出）+ 浅灰内容区，内容最大宽度 1120px。去掉面包屑、重复的页面标题、“服务器管理”小标题、写死的“已连接”标记和页脚。
- R3 宽度 ≤760px：侧栏变成底部标签栏，顶部显示品牌和“退出”；列表变成卡片；抽屉全屏；页面无横向滚动。
- R4 导航和按钮图标改用内联 SVG（原型中的图标），不再用 Unicode 符号。
- R5 每页页头只有一个 H1、一句说明和主操作按钮。

### 路由
- R6 使用 vue-router（history 模式）：`/` 概览、`/projects`、`/sites`、`/domains`、`/settings`。未知路径重定向到 `/`。刷新停留在当前页，浏览器前进/后退可用，页面标题显示为“<页名> · LPanel”。
- R7 登录状态仍由 App 统一判断：未登录时任何路径都显示登录页，登录后停留在原路径；退出后回到登录页。

### 登录页
- R8 单栏居中卡片：品牌、标题、账号、密码、登录按钮、版本号。保留现有校验、错误提示和提交中状态。

### 概览
- R9 4 个可点击的数字：容器项目数（副文字：已绑定域名的项目数）、静态网站数（单页应用数）、域名数（已启用 HTTPS 数）、证书需处理数（申请失败或 30 天内到期；有失败时显示红色，只有到期时显示橙色）。
- R10 “需要处理”清单：证书申请失败（显示错误，按钮“重新申请”）、证书 30 天内到期（显示剩余天数，按钮“续期”）、有新版本（按钮跳转面板设置）。没有事项时显示“一切正常”。
- R11 “面板访问”信息：访问地址、HTTPS 状态、证书邮箱、版本。
- R12 没有项目也没有网站时，“需要处理”换成“开始使用”三步引导（新建项目、新建网站、去绑定域名）。
- R13 数据全部来自现有接口（项目、网站、域名绑定列表、访问设置、升级状态）。任一接口失败时显示错误和重试，不显示 0 冒充真实数据。

### 列表页（容器项目、静态网站、域名与证书）
- R14 列表用自定义表格（桌面表格、手机卡片），每行露出一个最常用操作，其余收进“···”菜单：项目露出“部署”；网站露出“编辑”；域名全部在菜单中。菜单项与现有功能一一对应，不新增也不删减。
- R15 项目和网站行显示已绑定的域名；域名行显示用途、指向的项目/网站、证书状态（有效 / 即将到期 / 申请中 / 申请失败 / 未启用）、失败原因、到期日和剩余天数。
- R16 空列表显示图标、标题、一句说明和主操作按钮。
- R17 加载中、加载失败（带重试）状态可见。保留“刷新”操作。
- R18 删除、解除绑定前需要确认，沿用现有提示文字（例如“删除项目将移除容器和域名绑定，数据卷及挂载目录会保留。”）。面板自身的域名绑定不提供“解除”。

### 表单、抽屉与对话框
- R19 项目新建/编辑改为右侧抽屉（手机全屏）：名称、Compose、.env、“服务端口”区块（扫描端口按钮与结果表）。页脚只放“取消”和保存。
- R20 状态与日志改为抽屉：容器状态表 + 日志面板（深色等宽字体）+ 刷新。
- R21 网站新建/编辑、绑定域名、确认操作使用对话框，宽度不超过视口。必填项校验失败时在字段下方显示原因。
- R22 绑定域名对话框按目标分别调用现有接口：项目（需选择扫描到的端口，保留 http/https 选项）、网站、面板。从项目或网站行进入时预选该目标。

### 长操作
- R23 部署、启动、停止、重启、删除项目、申请证书、升级：提交后显示进行中状态，直到操作结果返回才提示成功或失败；失败显示错误原因和日志入口。`queued` 与 `running` 都视为未完成。
- R24 绑定或修改面板域名后，显示新访问地址链接（保留现有行为）。升级过程中的重新连接提示和刷新页面行为保留。

### 面板设置
- R25 “访问与证书”与“面板升级”两个面板纵向排列，最大宽度 760px。发布仓库输入框和“保存”按钮同行；“检查更新”“升级到 vX”放在面板底栏；升级前需确认。链接使用主题样式。

- [ ] 桌面 1440×900 与手机 390×844 下重新截图所有页面，与原型对比布局、配色、字号一致；手机宽度下没有横向滚动
- [ ] 刷新任一页面停留在该页；浏览器后退/前进切换页面；未知路径回到概览；未登录访问任意路径显示登录页，登录后回到该路径
- [ ] 每个列表页的加载、空态、错误、有数据四种状态都截图验证
- [ ] 至少一个长操作（例如部署）在结果返回前不提示成功，`queued` 状态不会被当作完成
- [ ] 菜单在表格底部行向上展开、不被裁剪；按 Esc 关闭并回到触发按钮
- [ ] 现有功能都能在新界面中找到：项目的 8 个操作、网站的编辑/绑定/删除、域名的编辑/申请证书/解除、证书设置、发布仓库、检查更新、升级
- [ ] 新增单元测试覆盖：证书状态与剩余天数计算、概览待处理事项计算、路由未知路径重定向
- [ ] `npm --prefix web run typecheck`、`lint`、`test -- --run`、`build` 全部通过

## Out of Scope

- 不修改后端接口。
- 不新增功能（例如签发环境选择、项目运行状态列），也不删减现有功能。
- 与界面无关的代码整理不做（例如按需引入 Element Plus、改动 `*-api.ts` 接口封装）。页面组件会按新界面重写，重写时允许抽出多个页面共用的操作轮询逻辑。
- `DomainsView.vue:12` 的 `poll` 只把 `running` 当作未完成，`queued` 时会误报“证书已启用”。证书流程按 R23 重写后这个问题随之消失，不另开任务。

# 实施与验证

1. 扩展项目读写、旧库默认值及压缩包元数据。验证端口范围、旧请求省略字段、显式清空和旧包导入。
2. 扩展项目绑定接口和绑定目标记录。在部署、启动和重启后保留固定目标，让原有 Docker 映射继续刷新。覆盖同项目两种绑定并存的回归场景，以及来自其他项目的端口无法作为本项目的手动候选提交。
3. 更新项目编辑器、共享绑定弹窗及其 TypeScript 契约。检查扫描为空或失败、扫描与手动候选并存、重复打开和取消编辑。
4. 使用仓库 .tmp 下的临时目录和缓存运行相关 Go 测试（go test ./internal/panel -run 'Project|Binding'），并在 web 下运行 npm run typecheck 和针对改动文件的 lint。核对项目入口及域名入口的实际交互。
5. 在可用的隔离 Docker 与 Nginx 环境，用监听本机 8080 的 host 网络服务检查域名访问及重部署后的响应，再验证扫描绑定仍跟随动态发布端口；记录实际验证环境和覆盖范围。

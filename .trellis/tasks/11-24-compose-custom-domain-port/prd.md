# 编排项目绑定域名支持自定义端口

## 目标与决定

管理员在编排项目的「服务端口」中添加宿主机端口，随项目保存。一个端口可供多个域名复用。典型场景是服务使用 host 网络并监听本机 8080，Compose 没有 ports 映射。

## 需求与验收

1. 创建或编辑项目时，「扫描端口」旁提供「添加端口」。可以添加、移除自定义端口。重复扫描保留手动输入，取消编辑放弃本次更改，保存并重新打开能看到原列表。端口取值为 1 至 65535 的整数。
2. 从编排项目或域名管理发起绑定，均能区分已发布 TCP 端口与已保存的自定义端口。没有扫描结果或扫描失败时仍能选择自定义端口，使用 HTTP 或 HTTPS 作为上游协议。
3. 两个域名可以使用同一自定义端口。对于本机回环地址可访问的 host 网络服务，通过域名能访问该服务。启动、重启或重新部署后继续指向原端口。移除项目候选只影响后续选择，已绑定的域名可在域名管理中单独解绑。
4. 已发布端口继续按 Docker 实际分配结果转发，包括已有绑定和同一项目内与自定义端口并存的绑定。
5. 项目压缩包携带自定义端口列表。导入旧包时列表为空；域名及证书仍由目标服务器管理。

## 范围

自定义项只指定本机端口。远程上游、修改服务监听配置、自动发现宿主机进程和开放防火墙端口均在本任务范围之外。

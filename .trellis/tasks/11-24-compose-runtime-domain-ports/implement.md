# 实施与验证

1. 在项目后端复用运行状态、容器归属及已发布端口逻辑，增加 host 监听发现和按项目查询候选的接口。聚焦验证子进程监听、两个 host 项目共享网络、宿主机自身的服务、停止的容器及相同端口的不同监听地址。
2. 扩展项目绑定入口，提交时验证自动发现的 host 候选，复用绑定保存、证书与 Nginx 生效流程。验证手动候选和 Docker 动态映射保留各自语义，过期候选返回可理解的错误。
3. 更新项目 API 类型和共享绑定弹窗。两处入口分别检查运行时端口、用户选择协议、空结果、部分读取失败、手动绑定、切换项目以及原配置扫描。
4. 运行定向 Go 测试、前端类型检查及受影响文件的 lint。浏览器验证弹窗；用隔离 Docker 与 Nginx 同时运行两个 host 服务和一个动态映射服务，确认候选归属、绑定后实际域名响应、重部署的结果。临时文件使用仓库 .tmp。
